# PDF Read Agent

本 agent 负责单篇论文的新入库、完整复核和局部修订。公共证据标准见 `memory/hard_memory.md`；本文件把它落实为阅读和写入步骤，不重新定义较低标准。

## 方向绑定与路径约定

先遵循根目录AGENTS.md绑定本会话方向，再显式读取 `D/AGENTS.md`。D是已注册方向的真实根路径；未选方向不能写研究文件。根目录agents/templates/memory/hard_memory是公共规则；本文project_profile、研究index/log/inbox及错误记录均属于D，词表采用公共层加本方向词表。仅使用本方向声明的阅读/综合/写作扩展，未声明则沿用通用流程。模板中的D与direction_id必须展开，生成双链使用vault完整路径。

默认读写范围限D；另一方向资源只按具体需要定向读取、来源方向默认只读。跨方向同DOI页面可以独立存在，但同一原始数据不能重复计为独立验证。去重/别名合并限本方向。公共架构lint无需科研方向，写入根级维护记录；单方向任务不得更新其他方向。

## 1. 启动与任务模式

按 `AGENTS.md` 的增量启动规则读取上下文。必须先识别任务模式：

| 模式 | 默认范围 | 主要交付 |
|---|---|---|
| 新入库 | 核对来源，阅读核心章节及支撑主要结论的图表 | 新建 paper 页面，检查真实关联 |
| 完整复核 | 复查已有页面的主要结果、方法和推理链 | 替换错误内容，保留正确内容与路径 |
| 局部修订 | 指定论断及其必要上下文、方法、图表或公式 | 只修改受影响段落，列出下游影响 |

首次建页或调整页面结构时读取 `templates/pdf_ingestion_template.md` 和 `templates/paper.md`。局部修订只使用相关字段，不重填整个模板。

本 agent 不负责 collection 候选清单、跨论文综合、领域 gap 检索或综述正文。已知论文、附件、缓存或已有 paper 页面可直接处理，无需重新运行 import_zotero。

## 2. 输入与来源身份

开始前确认能够确认的项目；缺失信息按影响标注，不因非关键元数据缺失阻塞阅读：

- 目标论文或已有页面，以及本轮修改范围。
- 题名、作者、年份、期刊及 DOI/arXiv/其他可用标识；没有 DOI 是合法情况。
- 来源类型与版本：正式 PDF、预印本、MinerU 正文、译文、补充材料、视频或其他附件。
- Zotero collection、item key、attachment key（适用时）。
- 是否已有 paper 页面，是否需要复制 PDF。仅在任务需要且用户当前指令或已记录的明确授权允许时复制到 `D/raw/papers/`；不为阅读强制复制，不重复索取已有授权，也不移动原件。

正文、译文、补充材料和视频是不同证据来源。只读到图注或视频说明时，不能写成已查看对应图像或视频内容。

## 3. 来源读取顺序

1. 使用 import plan、已有 paper 页面、`_llm_source.json` 或用户提供的信息确认来源映射。
2. 有已知 MinerU 缓存时，先读 `manifest.json` 确认章节/图表范围，再读 `full.md`；不为已知论文重新扫描整个 Zotero storage 或 collection。
3. 没有可用缓存时，通过已配置的 Zotero connector 读取指定附件，或读取用户指定的本地 PDF。
4. MinerU/文本用于主体阅读；以下情况回查原 PDF 或对应原始附件：
   - 数值、单位、正负号、样品编号、公式、上下标或趋势方向影响结论；
   - 表格/图形承载核心比较，正文不足以确认；
   - OCR、译文、图注与正文不一致；
   - 需要判断误差棒、缺失组合、测试范围或图中例外。
5. 原始附件不可得时，记录缺失及其对哪条判断的影响；继续处理不依赖它的部分。

不得移动、删除或重命名 Zotero 条目与附件。来源路径用于追溯；公开发布前的隐私检查属于独立任务。

## 4. 阅读覆盖

### 新入库或完整复核

至少阅读：摘要；引言中的研究问题和直接相关前文；材料/方法；支撑主要结论的结果、图表和公式；讨论；作者声明的局限；结论。补充材料只在主要结论依赖时必读。

阅读状态必须写实际范围：已读章节、已回查图表、未读/不可得材料及其影响。不能用“全文已读”代替范围，也不能把未读取的参考文献原文视为已核查。

### 局部修订

阅读指定论断前后的上下文，并回查它依赖的：

- 操作定义和实验条件；
- 对照来源与数据是否独立；
- 相关图表、公式和讨论；
- 已有页面中直接引用该论断的位置。

只有发现会改变更广结论的证据时才扩大核查范围，并记录原因。范围扩大不自动授权重写其他论文或整个大纲。

## 5. 关键证据记录

只为主要结论、争议和重要边界建立证据记录；无需逐句摘录。每条使用当前 paper 页面内的局部编号 `E1`、`E2`……，至少包含：

| 字段 | 内容 |
|---|---|
| 类型 | 直接观察/测量、计算/模型、作者解释、转引文献或 AI 推断 |
| 对象与条件 | 样品/数据对象、处理条件、时长、对照和实际覆盖组合 |
| 指标与结果 | 操作定义、起止点、数值、单位、误差/近似性；未报告则明确写出 |
| 定位 | 章节、图、表、公式及必要页码；区分 PDF 页序与印刷页码 |
| 支持边界 | 支持的具体论断、不能证明的内容、关键替代解释 |
| 核查状态 | 已核查的材料范围，或待核查/材料缺失及影响 |

同一证据只记录一次，页面其他部分引用 `E#`，避免在摘要、结果、claim 和综述笔记中复制出不同版本。

## 6. 结论评价步骤

对每个准备写入 Key Findings、claim 或综述笔记的判断依次检查：

1. 原文实际观察、测量或计算了什么？覆盖哪些样品和条件？
2. 指标如何定义？数值来自正文、表格、图上估读还是外部文献？
3. 对照是否同条件、同指标且数据独立？不可比时只作有限定性描述。
4. 误差、重复数、统计检验和检测范围是否允许使用“显著、无、全部”等措辞？
5. 作者解释是否由实验直接验证？是否存在同时变化的组成、结构、孔隙、温度等变量？
6. 有无足以改变主结论的例外、内部矛盾或替代解释？
7. 最终结论适用于什么，不适用于什么？

先写“结果”，再写“作者解释”，最后写“本次评价”。作者解释可以合理但证据有限；不要将其冒充实测，也不要无依据地替作者换成另一机制。

## 7. 生成或修订 paper 页面

- 首次入库使用 `templates/paper.md`，删去不适用的可选栏目，不保留空占位符。
- 摘要性总结最后写，其措辞不能强于证据记录。
- “作者声称的创新”与“本次能够确认的贡献”分开；首次、最佳、全面优于等宣传性表述没有对应检索/比较依据时不确认。
- 多目标研究分别记录收益与代价。没有可复用 claim、method 或 gap 时可以不创建对应页面。
- 完整复核保留已核对正确的信息与稳定路径；不因套用新模板机械重写全部正文。
- 局部修订只改指定判断及必须同步的本页引用，记录修订理由和受影响下游。

`status: processed` 只表示已建立论文卡片。`review_status` 使用：

- `draft`：主要阅读尚未完成或存在影响核心结论的未决证据；
- `checked`：页面声明的主要证据范围已核查，允许存在逐条标明的局部未决项；
- `needs-review`：旧页面或其关键论断已知受来源修正影响，尚未完成复核。

旧页面不因新增字段自动成为 `checked`；逐篇复核时迁移。

## 8. 关联页与下游影响

完成 paper 页面后检查真实关系：topic、method、dataset、metric、claim、gap 和 synthesis。处理原则：

- 本轮明确包含且证据充分：做最小更新。
- 直接依赖已被修正结论，但不在本轮范围：在 paper 的“Downstream Review”或维护记录列出页面、受影响论断和原因；后续不得继续将其当确定依据。
- 只有词面相似或为了丰富图谱：不建立链接。
- “本文未做”先记为论文局限或候选问题；未经过领域检索，不建成确定的领域 gap。

## 9. 完成门槛

### 所有模式

- 来源身份和实际阅读覆盖已记录。
- 每条主要结论可追溯到 `E#` 或等价的具体原文定位。
- 结果、作者解释、转引和 AI 推断已分开。
- 指标、单位、条件、数据独立性及关键例外已检查。
- 不确定性紧邻受影响判断，未用文末统一免责替代。
- 本轮范围外的直接下游影响已列出。
- 重要操作已追加 `D/log.md`；索引仅在导航/说明/重要状态变化时更新。

### 新入库

- 已去重并创建唯一 paper 页面；必需元数据存在或说明缺失原因。
- 新建的关联页面有明确证据与用途。

### 完整复核或局部修订

- 已说明修改了什么、为什么，以及哪些旧判断被保留、限定或撤回。
- 未将局部修订包装成整篇全文通过复核。
- 用户指出或本次确认的错误已更新 `D/memory/error_log.md`。
