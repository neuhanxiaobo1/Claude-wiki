# 电子封装方向术语

遵循根memory/term_aliases.md。以下作为初始检索和记录口径；尚无对应topic/method/metric知识页，不为术语表创建空壳页。仅在语境与含义一致时应用别名。

| 主术语 | 同义写法/检索表达 | 使用边界 |
|---|---|---|
| Electronic Packaging | 电子封装、electronic packaging | 本方向名称，不表示所有封装主题均为本轮范围 |
| Silver Paste | 银膏、silver paste；本方向对象为烧结使用的电子银膏 | 具体用途须核对；不把所有导电胶或含银连接材料自动并为同一对象 |
| Sintering | 烧结、sintering | 保留原文工艺定义，不自动与固化、回流、soldering等合并 |
| Shear Strength | 剪切强度、shear strength | 原文若给shear force/load，保留为载荷，不当同义单位直接替换 |
| Porosity | 孔隙率、porosity | 定义和统计对象需一致；void fraction等相关词先核对，不无条件统一 |
| Thermal Conductivity | 热导率、导热系数、thermal conductivity | 仅相同物理量/语境下使用；热阻、热扩散率另列 |
| Electrical Properties | 导电性能、电学性能相关检索表达 | 这是指标组入口；conductivity、resistivity、resistance分别记，不作为彼此同义词 |

用户原词“焊接温度”保留为关注项。目前不将它登记为“烧结温度”的无条件别名；论文阅读时按实际过程和温度阶段确定记录字段。
