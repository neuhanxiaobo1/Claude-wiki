# 电子封装研究配置

## 用户已确认信息

- 方向名称：电子封装。
- 主要研究对象：烧结使用的电子银膏。
- 主要指标：焊接温度、剪切强度、孔隙率、热导率、导电性能等。
- 来源：用户2026-09-09本轮直接说明；个人身份与默认语言沿用根 [[memory/user_profile]]。

## 研究范围

优先整理与烧结用电子银膏及上述指标直接相关的论文。具体封装应用、连接对象、浆料配方、颗粒尺度、承压/无压工艺、基材及表面状态随用户指令和实际论文细化，不预设某一技术路线。

一般电子封装文献及其他连接材料可在与本方向任务有明确关系时作为背景或对照，不自动批量纳入；用户尚未给出硬性排除范围。核心研究问题、创新点与预期成果类型尚未确定，不能由检查清单自动推定选题。
