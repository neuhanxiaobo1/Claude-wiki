# 电子银膏：总结、比较与写作补充规则

仅作用电子封装方向；配合根synthesis_agent、gap_agent及review_agent。用户已指定五类主要指标，以下顺序是工作格式，未给指标权重或数值阈值，不将它写成用户已确定的创新方向。

## 1. 比较前先分组

以研究问题选择本轮论文，优先按实际配方/样品、连接工艺及测试对象建立可比组。温度与时间、压力、气氛一同记录；同名指标还需核对方法、单位、几何、测试状态和误差。比较资格使用公共标准的直接可比、仅定性或不直接可比。

同一篇论文的不同样品/工艺分别列行；同源数据跨论文引用保留共同来源标识，不重复计数。材料层面结果与接头/结构结果不得在没有依据时互相代替。

## 2. 最小比较表

实际开展综合时再生成表格；当前不创建占位综合页。每行对应可追溯的“论文＋样品＋工艺＋测试状态”，至少提供：

- 材料/样品身份与主要组成信息（原文未报告则说明）。
- 连接/烧结温度，以及配套时间、压力、气氛。
- 剪切强度、孔隙率、热导率、导电性能：各保留原指标名、单位、测试对象及条件；未报告项不补齐。
- 原文图表/页码或论文页证据编号、证据类型、核查状态、比较资格及主要限制。

不同定义的电学量/热学量不要硬塞进同一列排名；必要时拆列或分表。具体领域记录口径见 [[directions/electronic-packaging/memory/reading_rules]]。

## 3. 总结与写作顺序

先回答本轮研究问题，再依次说明材料与工艺条件、五类指标的实际证据覆盖、可比较的结果、收益与代价、未决项和待验证解释。顺序服务于可读性，不要求每篇都有五项结果。

没有用户指定权重和合理比较依据时，不计算综合评分或宣布唯一最优；“低温”“高强度”等措辞说明对照和条件。跨论文结论保持必要限制，不将不同样品的优势拼接成不存在的配方性能。

## 4. Gap与跨方向借鉴

单篇未测某项性能先记论文局限；本库未覆盖先记语料缺口；领域gap仍需明确检索范围与反证。不得因为五项指标未齐就自动认定创新点。

其他方向方法可定向借鉴，但仅写接收方向的独立评价，保留来源完整链接、原条件、版本/日期和未验证部分。共同术语不代表证据可直接移植，也不触发来源方向重写。
