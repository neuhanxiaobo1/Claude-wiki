# 烧结用电子银膏：阅读补充规则

仅作用电子封装方向。用户确认研究对象与五类主要指标；以下具体核对项是本次据此组织的阅读工作清单，不是用户已选技术路线、作者结论或研究结果。公共证据标准不变。尚无真实论文试运行。

## 1. 先绑定材料、工艺与试样

按本篇主要判断所需记录，缺项写“未报告/待核查”，非适用项可省略：

- 材料：银膏名称/编号；论文提供的组成、颗粒尺度或分布、添加组分与含量口径；配方未公开时明确未报告。
- 工艺：原文的连接/烧结过程名称；各阶段温度、时间、压力、气氛及加热历程；设备设定值和样品测量值分别记录。
- 对象：自由材料、膜层、烧结层或接头等原文对象；连接双方材料、表面处理、连接面积/厚度/几何信息按实际报告记录。
- 样品身份：各项性能是否属于同一配方、同一工艺和同一批次；不把不同优化条件下的最好数值拼为一个“综合最佳样品”。
- 试验状态：初始状态、处理后或服役模拟后等按原文分列；性能变化需能对应到明确样品和试验条件。

## 2. 五类主要指标

| 指标 | 必要核对项 | 比较边界 |
|---|---|---|
| 焊接/连接温度 | 用户称“焊接温度”；论文的实际工艺名、温度所在步骤、峰值/保温值、时间、压力和气氛；区分工艺温度与性能测试温度 | 不把预处理温度、形成接头的工艺温度、测试温度或作者声称的使用温度混为一列；不给“低温”擅设阈值 |
| 剪切强度 | 原始强度或载荷及单位、有效面积依据、接头几何、测试温度/加载条件、重复数/散布；断裂位置或模式仅按证据记录 | 原文只给载荷时不直接改称强度；换算必须有足够定义和尺寸依据。不同结构、面积口径或测试条件先分组 |
| 孔隙率 | 数值/单位、测量或图像分析方法、表面/截面/体积等统计对象、取样位置/范围及算法口径；是否有误差或重复 | 保留作者的孔隙/空洞命名与定义，不把不同统计口径自动合并，也不从一张局部图推定整体孔隙率 |
| 热导率 | 原名称/单位、材料或接头对象、测量温度/方向、试样尺寸、方法；若由其他量推得，记录计算方法及输入来源 | 热导率、热扩散率、热阻等分别列出；跨对象和方法比较先核对定义，不把模型结果改写为直接实测 |
| 导电性能 | 原文实际指标名称，如电导率、电阻率或电阻；原单位、测量温度、对象、几何/厚度与测试方法；接触贡献是否说明 | 不将不同电学量混在同一数值列；需要换算时保留原值、关系和必要条件，资料不足则不换算 |

五项未全部报告不等于论文无用。明确哪些已读、哪些未报告、哪些与本轮任务无关；不得补造数据或统一填写“已验证”。

## 3. 证据与因果

先核对原文，再写总结。数值、单位、样品编号、图表和计算来源遵循根hard_memory。作者机制解释与直接观测分开；观察到孔隙率与某项性能同时变化时，核对其他条件及对照，不能自动写成唯一原因或可推广定律。

不因一个指标较好就宣称五项全面占优；论文主要结果需同时保留工艺条件、改善与代价、测试对象以及统计边界。可靠性或长期表现仅在原文有相应试验/分析时记录，未测试部分不外推为已验证。
