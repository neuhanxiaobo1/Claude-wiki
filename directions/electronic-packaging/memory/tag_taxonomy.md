# 电子封装方向标签

命名、处理状态与证据边界遵循根memory/tag_taxonomy.md。以下是2026-09-09依据用户明确范围建立的初始检索词表；只登记在本方向，不意味着对应知识页已存在。

| 标签 | 用途 |
|---|---|
| electronic-packaging | 电子封装方向 |
| silver-paste | 电子银膏研究对象；按论文说明是否用于烧结 |
| sintering | 论文确实讨论烧结过程时使用 |
| joining-temperature | 用户关注的焊接/连接温度；具体工艺名和阶段保留正文定义 |
| shear-strength | 剪切强度相关研究；原文仅载荷时仍需明确原指标 |
| porosity | 孔隙率相关研究；保留测量与统计口径 |
| thermal-conductivity | 热导率相关研究 |
| electrical-properties | 导电性能及相关电学量，具体指标另列 |

论文按实际内容选用标签，不强制全部添加。公共paper、claim、needs-review等标签沿用根词表；新增专业标签先检查本方向同义项。
