# 错误记录

本文件记录本方向实际发现与修正。公共创建编码问题记于根memory/error_log.md。

## 2026-09-17 | 将工具未暴露误当成来源访问阻塞（已修正）

- 表现：此前因当前工具列表无Zotero接口、插件目录无结果，要求用户连接或提供导出，未能利用已配置的本地MCP。
- 原因：工具列表/插件目录与本地MCP服务可达性未区分；此前未获端点，不能据此推定本机服务不可用。
- 修正规则：用户提供端点后，直接只读核验initialize、tools/list及集合读取；确认本地服务可用并完成元数据导入。
- 影响范围：本方向来源配置、短状态、inbox和索引的访问阻塞说明，已更新；未影响科学结论。
- 以后避免方式：准确区分“未暴露为当前工具”和“服务不可访问”；对用户提供的本地端点先实测，保留原件保护边界。

## 2026-09-17 | 源文图文冲突与解析错误（已限定，原件未改）

- 表现：单硅酸盐高温tanδ阈值与Fig.7不一致；多孔Si3N4摘要强度与正文最大值不同；高熵二硅酸盐正文323 K与Fig.5的373 K起点不同。焦磷酸盐Markdown将TiP2O7退火1400 °C识别为140 °C；高熵论文Zotero日期与原文发布日期不同。
- 原因：前三项是原文报告层面的差异，不能由本次阅读确定究竟笔误或统计口径不同；另有OCR及书目元数据误差。译文/解析文本不足以裁决原文冲突。
- 修正规则：原PDF核查后，OCR明确错误在知识页按PDF记录；无法裁决的值保留冲突、不自行替换。高熵论文发布日期按原文2026-06-01记录，Zotero保持不动。
- 影响范围：[[directions/wave-transparent-composites/wiki/papers/Du-2024-RE2SiO5#E3]]、[[directions/wave-transparent-composites/wiki/papers/Liu-2024-Porous-Si3N4#E2]]、[[directions/wave-transparent-composites/wiki/papers/Wen-2026-High-Entropy-Disilicate#E3]]、[[directions/wave-transparent-composites/wiki/papers/Liu-2024-Entropy-ZrP2O7#E1]]及高熵页元数据说明；无既有本方向科学下游需撤回。
- 以后避免方式：对阈值、指数、最优配方、测试温度及均值/最大值回查原图；不把摘要指标移植到不同工况。全部paper保持draft，争议值使用前复核。

## 2026-09-17 | 入库生成命令超过Windows长度限制（已修正）

- 表现：将9篇阅读记录嵌入单次PowerShell命令触发CreateProcess错误206；随后一次补丁尝试对同路径同时删除/新增被校验拒绝。
- 补充：首次只读校验脚本有多余右括号，解析时退出；修正后重新运行，9份来源哈希及映射核验通过，无数据写入受影响。
- 原因：长命令超过Windows限制；补丁接口不接受同路径重复操作。
- 修正规则：使用工作区临时数据/脚本生成新页面，已有文件使用单次Update；失败时没有产生对应写入，成功后核验实际文件。
- 影响范围：仅本次生成过程，无原始文献或科学数值受影响。临时构建文件在完成后移除。
- 以后避免方式：大型正文使用文件/补丁传递，避免命令行承载全文；同路径补丁只提交一次更新。
