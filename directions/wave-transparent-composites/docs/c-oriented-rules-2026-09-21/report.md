# C方案优先：机制证据与综述写作的方向规则完善方案

## 1. 当前决定及方案定位

用户已提供三方案总结并明确更倾向C。本方案以C为优先验证主线，不继续采用旧稿“A优先、C备选”的排序；“倾向C”不等于最终标题、应用温区及全部章节已经定稿。用户文件《Ceramic_Based_21, 2026.md》保持原样，[路径与哈希](user-source.json)记录只读来源。

C的工作题目为“陶瓷基透波复合材料的多尺度介电响应与电磁波传输机制”。中心问题：组成与实际结构变化如何影响介电响应，哪些证据能把这种响应进一步连接到电磁波传输？若关键机制链缺乏支撑，收窄为“介电响应调控与结构—性能关系”，不强行完成多尺度机制闭环。

相较上一轮泛用方案，本版以四个动作取代单纯增加字段：**按因果环节筛选、按可观察量阅读、按证据链综合、按论证问题写作。** A中的结构/力学作为设计约束与对照，B中的热环境作为响应条件与扰动；不平铺并写三篇综述。

本轮交付为具体可实施方案及指定参照阅读报告，未启用新方向扩展、未重写27篇paper或升级其核查状态、未把用户材料迁入raw或修改原件，未改公共规则/其他方向。采用C后的专项改动只允许在directions/wave-transparent-composites内发生。

## 2. 两篇写作参照的地位

已定位“组内文章→博士”直接成员中的两篇指定文献：

- Nature Reviews Bioengineering 2024社论，DOI 10.1038/s44222-024-00256-4：全文阅读，提炼问题意识、平衡比较、清晰表达与可执行展望。
- Tang et al. 2021，Polymer matrix wave-transparent composites: A review，DOI 10.1016/j.jmst.2020.09.017：定向阅读概念、机制、代表段落、测试与展望；学习物理引入、材料例证及组织方法。

实际覆盖、定位、可借鉴与不可迁移之处见[指定参照阅读记录](style-reference-notes.md)。两篇被指定为写作质量参照，不成为陶瓷机理论断的默认科学权威；不因目录叫“组内文章”自动称作者为本组。Tang属于树脂基背景，不转成陶瓷核心证据。社论的近期文献数量经验不设为硬门槛，任何期刊风格也不构成投稿成功保证。

## 3. C方案的论证单元：不要把分类当机制

每个拟写判断应能落到以下链条中的明确部分：

**设计变量/工艺 → 实际组成与结构 → 候选物理过程 → 介电响应 → 在边界条件下的传播/反射/耗散/透射。**

各段可以由不同来源支撑，但连接前必须核对材料状态、尺度、频率和条件是否可传递；不是要求每篇论文都覆盖全链。缺少某一段就显式标记，不用理论术语补齐。

原子/微观/构型是结构层级；极化、导电、弛豫等是候选物理过程；有效介质是建模层级；DFT、介电谱、场模拟是方法。四者分别记录。掺杂、打印、混编、界面涂层是设计手段，不能直接命名为已验证机制。

建议每个核心小节首先提出一个可回答的问题，例如“某类界面变化是否改变目标频段的损耗，还是主要通过密度/相组成改变有效参数？”随后组织比较、模型及例外；不先规定所有极化机制都必须分章。

## 4. 入库规则：用途与证据贡献分开

沿用原身份核对、稳定编号、来源/附件去重流程。仅新增C用途及其理由，不增加一个含混的‘机理型好论文’总分。

| 用途 | 可纳入的来源 | 对核心正文的贡献边界 |
|---|---|---|
| 陶瓷复合体直接证据 | 明确增强/多相/层合/网络结构的研究 | 支撑对应材料、状态、条件的实验或模型结果 |
| 组成/基体/组分参照 | 稀土单相陶瓷、单体PDC、纤维/界面独立研究 | 解释链条局部；不得当作复合体已验证结果 |
| 机制/方法来源 | 相关介电物理、有效介质、测试与电磁模拟原始研究 | 说明适用模型或可辨识量，保留材料与频率迁移边界 |
| 写作参照 | 本次两篇指定文献 | 指导论证和表达，不补充不存在的物理证据 |
| 跨体系/范围外 | 树脂及纯吸波等 | 只在明确问题下引用，禁止吸收增强直接转为透射增强 |

候选优先级按是否补关键链条、提供反例/严格对照、验证频段或模型来定。无DFT不降级，有DFT不自动优先；只有性能数据的论文仍可提供重要边界和对照。每篇至少说明“它补哪一段、不能补哪一段”。检索记录保留数据库/日期/检索式/限制/筛选阶段，现有集合不冒充领域全集。

## 5. 阅读规则：新增三个C专用模块

### 5.1 介电与传输条件模块

提取ε′、ε″、tanδ的定义、频率和温度；对象方向、测试方法、密度/孔隙、几何与热/湿历史按论断需要记录。涉及传输才启用厚度、入射角、极化、层序、参考介质、端口/校准、功率或幅值定义。没有报告写NR，未核写NV，不适用写NA。

不能只看低ε′就认定高透射；不能把复介电参数反演结果、直接S参数、模型T混成同一证据。模型使用磁导率简化、均匀/各向同性或平板边界时须记录假设，不能从材料名称自动代入。

涉及反射/吸收/透射关系时，核对是否采用功率归一化、散射和全部通道是否计入；不能未经定义就从符号T或S21推出可跨实验比较的百分比。正文只写本题需要且已有来源核验的关系，公式库先建最小集，不做无条件公式大全。

### 5.2 机制辨识模块

对作者提出的每个机制问：观察到了什么？何种独立证据支持过程？其响应时间/频段/温度是否与目标测量一致？控制变量有没有改变？什么竞争解释仍成立？

| 作者常见解释 | 阅读时的具体追问 | 无支撑时的处理 |
|---|---|---|
| 界面极化改变 | 有何温频谱/对照支持？导电、吸湿、相含量是否也变化？ | 记录作者解释，不把界面存在当过程证明 |
| 残碳/缺陷导致损耗变化 | 含量、连通性、缺陷证据与测试条件能否对应？ | 保留关联，明确变量共变 |
| 孔隙降低有效介电参数 | 孔隙类型、密度、相组成和方法是否一致？有模型验证吗？ | 不单独归因为孔形或局部场机制 |
| 掺杂/键合降低极化 | 计算对象、响应分量与实测频域是什么？是否含离子/电子等实际计算贡献？ | 不由DOS、CDD、Bader/ELF图直接推得完整微波损耗 |
| 构型改善透射 | 是否改变厚度、取向、层序？是实测还是求解结果？ | 不把几何模型结果当材料本征常数 |

这些是核查问题，不是预设某种过程必然存在或不存在。电子/离子等对目标频段的贡献不能简单依据“共振频率高低”一概判零，也不能将所有低频过程都套到GHz；具体模型和条件须回到物理来源。

### 5.3 模型与跨尺度模块

DFT记录输出到底是结构/电荷、某响应分量、静态张量或光学谱；明确未包含的散射、缺陷/载流子、孔隙及有限温度等，仅按实际方法认定。禁止把光学计算谱直接改写为GHz完整复介电谱。

有效介质模型记录混合规则、体积分数、相形态、方向性及适用尺度；比较数据是否用于拟合和独立检验。电磁模型记录参数来源、几何与边界、网格/收敛及可用实验验证，不要求所有论文提供未报告信息。

尺度连接需要“上游输出→下游输入→转换/平均假设→验证对象”记录。把三种尺度的图片并列不等于多尺度耦合；不同论文连接为解释框架时标综述综合推断，而非同一实验闭环。

机器学习记录目标、特征、独立来源/数据划分及外推范围；特征重要性不是因果证据。LLM负责抽取、组织和假说候选，不能作物理真值；不存在实验高于计算的统一等级，评价的是某方法是否支持当前论断及是否经适用范围验证。

## 6. 记录规则：最小数据行与机制卡

保留paper E#为科学证据主记录，不重编号、不用新卡替代原件定位。局部机制卡可直接置于paper现有总结/局限栏目；只有跨文献反复使用且关系明确时才建claim页。

**最小数据行：** paper/E#、样品/系列、实际变量与对照、测量或计算量、值/趋势及单位、必要条件、来源定位、核查范围/未决。图估读、转引、数值换算单独标记，原值保留。

**机制卡：** 待解释现象；对应链条环节；候选解释；支持证据及模型假设；混杂/替代解释；可采用的限定判断；缺失的区分证据；拟服务章节。不是要求每篇具备完整机制，只记录其贡献边界。

沿用现行supported / partially-supported / insufficient-evidence / contested及review_status定义，不引入把‘实验、模拟、AI’机械排成高低的评分。论文页draft不能被矩阵自动洗成checked；局部复核必须记录具体范围，最终正文准入服从公共review流程。新增扩展不能悄悄覆盖公共证据门槛；如需调整公共状态规则，另提范围明确的公共任务，本轮不改。

派生矩阵引用E#和提取日期；若重读修正某证据，检查直接依赖的数据行、图和句子。仅缺一段就限制那段，不把整篇一刀切排除或全部放行。

## 7. 综合与写作：从‘按尺度分章’进一步改进

用户C稿的8章适合作为问题清单，但若依次写物理—原子—微观—宏观—表征—模型—AI，会产生同一机制在不同章节反复讲述。建议候选架构收敛为：

1. **范围与问题**：何为本文的陶瓷复合体，为什么需要连接介电响应与传输，而非仅汇总低ε。
2. **连接响应与传输所需的最小物理和测量框架**：术语、频温条件、参数/传输区别、模型边界；长推导放框或附录。
3. **组成与局域结构如何影响响应**：用实际案例比较证据与替代解释，单相陶瓷注明为基础参照。
4. **相、界面及孔结构如何改变有效响应**：对照、耦合与可辨识性为主线，不按材料逐一罗列。
5. **增强构型及几何如何连接到电磁传输**：取向、层合/网络、各向异性与传播模型，区分材料效应和几何效应。
6. **跨尺度联系、冲突与条件性设计认识**：汇总前章能连通/尚未连通的证据，检验外推。
7. **可执行展望**：最重要的未决过程、所需对照/可观察量、模型验证任务。

实验表征和模型随其解释问题嵌入3—5章，6章仅讨论接口与有效性，避免再列一次仪器。数据驱动/LLM暂作框或展望，满足真实相关证据后才升独立节。力学/热学用于解释可用设计空间或材料状态，不回到A/B的全量指标百科。

每节采用“问题→最小解释框架→代表性证据比较→反例/未决→有条件的综合认识→下一问题”。顺序可因论证调整，不机械要求每段六句。先在笔记中完成论证，再独立写句子，不按参照文章逐句换词。

表达要求：短而连贯的句段、首次定义关键术语、统一英文名与符号、避免无依据‘显著/卓越/突破/首次/协同’。‘表明’须有直接结果，‘归因于’说明是谁的解释；‘证实机制’须说清哪一段、排除了什么，而非只换更强动词。

## 8. 图表与公式的专项门槛

优先制作三类原创图表：机制链及断点图；频率/温度与测量/计算覆盖图；结构变量—可观察量—候选过程—证据边界比较表。每个箭头和数据点能定位，图中区分测量、模型、解释；不会因为画成实线就获得科学确定性。

多尺度总图中的无证据连接标为待验证，不制造统一已证实机制；不同方法温频范围不要填满不存在的网格；同源转引不重复计数。

公式登记最低包括：出处/原始定位、符号及量纲、约定、成立假设、可用场景及不适用场景。发现原文符号疑点保留位置并停止依赖该式的推导；不在风格学习任务中自行修正文献或编写复算代码。Tang式(2)与此前Yu计算透射公式疑点说明有必要单独设这一检查，但不能据此断言两文一定同源错误。
