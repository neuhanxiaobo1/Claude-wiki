## 参照二：Tang综述的有效写法及改造方式

1. **先界定研究对象，再解释必要物理。** §1—3先介绍功能、复合材料单元与介电/透射概念，再进入材料细节。可借鉴逻辑依赖顺序，但C应把物理引入限定为后续案例需要的内容，避免另写介电教材。
2. **先提出调控路径，再用研究实例展开。** §4.2先描述降低极化相关响应、改变结构和兼顾耐热的策略，再给改性案例。C可采用“候选过程→可观察量→对照案例→替代解释”的结构；不能移植聚合物链段、交联或含氟改性的结论到陶瓷。
3. **把改性前后比较落到对象。** §4.2、§5.1包含配比和对照指标，适合学习如何支撑比较句。C必须进一步明确频率、温度、密度及是否同批样品，不能照抄本文所有省略条件的写法。
4. **图表解释关系。** PDF第3页Fig.2给出组分/界面，第4页Fig.3连接入射、反射、损耗与透射。C应原创绘制本题证据链与尺度转换图，不复刻其图形布局或借用示意图替代数据。
5. **测试服务于可解释性。** §6可借鉴“测得什么量→如何获得介电参数”的组织意识；C不必为每台仪器单列一章，重点是方法能支持哪一段判断及误差来源。
6. **结尾从具体障碍提出任务。** §8从界面、协同性和模型提出未来问题。C应将展望进一步收紧为待区分的解释、补充测量/模型和预期判别结果，而不是重复“高性能、智能化、多功能”。

## 不照搬的内容

- Tang §3原PDF第3页式(2)分母确写δ−sin²θ，符号与物理适用条件须核；式(4)及正文涉及T与幅值平方，不能未核即搬入当前综述。此处记录来源符号疑点，不擅自替原文勘误。
- 部分极化分类、例证及概括性因果说法需要回原始文献验证。§3.1引用电子束极化仪的例子，不能直接用作陶瓷微波介电响应证据；本轮未追原文裁定其适用性。
- §3和§4中“降低介电参数即可提高透射”等概括，不能替代指定厚度、频率、入射和边界条件的验证；模型简化需另列假设。
- 树脂中更强界面结合的设计目标不能直接迁移为陶瓷复合材料唯一最优策略。
- 逐项材料列举、连续“某作者做了什么”、大量泛称优秀的修饰及未限定比较，不作为必须模仿的风格。
- 不复用长句、段落骨架、独特比喻、图形布局或引用序列；先形成自己的证据矩阵和论点，再独立写作。

## 建议的表达准则及原创示例

词语强度由本句证据决定：测量支持用“测得/观察到”；作者归因用“作者将其归因于”；部分一致用“与……解释一致，但未排除……”；本综述判断用“综合这些限定条件，可提出……”；待验证机制用“可能/有待检验”。不以统一替换词表机械降调，也不以“证明、显著、协同、首次”增加气势。

**不宜写：** 增加孔隙显著抑制界面极化，从而大幅提高透波性能。

**独立表述示例（仅演示论证，不指代某项实测结果）：** 某孔隙调控系列在指定频段呈现较低的有效介电常数。若相组成与密度同时变化，现有对照只能支持结构变化与介电响应之间的关联，尚不足以单独确认界面极化贡献；透射是否改善，还需结合厚度与入射条件验证。

示例必须在实际写作中替换为具体材料、条件、数据和引用，不允许直接作为无来源科学结论。高水平写作的验收应看问题是否清楚、证据是否相称、解释是否可区分、读者是否得到新的综合理解，而非长句、术语密度或期刊口吻。
