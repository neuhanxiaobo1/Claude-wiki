## 1. 结论与本次交付边界

需要细化，重点是本方向的领域字段和从证据到论证的转换。公共规则已经要求原件保护、证据定位、实测/计算区分、条件可比性、独立来源、反证和写作追溯，不宜再复制一套更长的公共规则。建议在本方向建立阅读、综合、写作三个薄扩展，并用小规模试点检验是否真正减少后续返工。

用户本轮已明确目标为“陶瓷透波复合材料综述”；仍未固定为高温航空雷达罩，频段、服役温区、期刊与最终题目待收敛。以下研究问题、分类细则、字段和大纲是建议，不是已经证实的领域结论，也不是已经启用的新规则。本次完成现有规则审计及实施方案，不批量重写27个paper页、不升级其review_status、不新增未经阅读的科学结论。

依据：根AGENTS及hard_memory；import_zotero、pdf_read、synthesis、review公共流程；paper/review模板；本方向profile及入库/用途报告。本次没有进行新一轮外部领域检索或逐篇全文复核，不能由此声称选定的综述切入点具有新颖性或语料已完整。

| 保存/恢复 | Git保存派生知识，外部原件只读 | 可发布管理快照与外部原件备份分开 | 远端恢复后清单链接失效，误以为已完整备份 |

## 3. 先建立一页综述工作契约

建议采用“问题导向的批判性综述，检索过程可追溯”作为暂定形式。没有执行系统性检索与筛选前，不自行标为系统综述或荟萃分析。

工作问题建议：**陶瓷复合材料如何通过组成、增强体、界面、孔结构和制备工艺，在规定的电磁与热力环境中协调透波、承载和热稳定性？现有证据在哪些条件下支持这些设计策略？**

契约应记录：目标读者、材料边界、应用/频率/温区、检索截止日期、纳入文献类型、拟回答的3—5个问题、非目标内容和变更记录。期刊、语言与字数可暂缺，不影响先建矩阵；明确应用边界前不设统一性能门槛。

建议问题：

1. 何种材料构成与微结构变量影响哪些电磁、热学和力学指标？
2. 工艺如何改变孔隙、界面、残余相、取向和缺陷，而不是只列工艺名称？
3. 性能改善的代价是什么，最优条件是否属于同一样品与同一测试状态？
4. 室温低损耗证据如何延伸至高温、热震、氧化、湿热或构件验证，哪些环节仍缺数据？
5. 当前比较受哪些方法与条件差异限制，下一步研究应补什么证据？

组内经验用于发现问题、判断实验可行性；综述外部覆盖不以本组材料或设备能力为纳入上限。大模型是可选工具或有证据时的展望内容，不因历史选题偏好强制设章。

## 4. 入库与用途规则

分开记录“知识库是否保留”“文章中承担什么作用”“本条证据能否引用”。三者不能用一个核心/非核心标签替代。

| 建议用途 | 纳入方式 | 当前典型边界 |
|---|---|---|
| 核心复合材料 | 陶瓷为主要基体/骨架，增强、多相、界面或结构复合直接服务透波问题 | 连续/短纤维增强、多相复合、核壳网络等，需按实际组成确认 |
| 基础参照 | 单相陶瓷、纤维/界面单独研究、相关基体 | 可用于机理和设计来源，不计为复合体综合性能 |
| 方法辅助 | 介电/热力测试、可靠性、模型与数据方法 | 应对应明确章节功能，不因方法通用而成为材料主线 |
| 跨应用对照 | 炉衬、其他透波构件、树脂基体系 | 明确迁移内容与不适用条件；不可合并性能排名 |
| 范围外档案 | 无透波关联的吸波、腐蚀等 | 留存历史，不进入本文核心语料；不自动删除Zotero |

特殊情况：多孔不自动等于复合材料；PDC是制备来源而不是复合结构定义；单体SiBCN须据相组成和文章操作定义判用途，不能由含多元素自动归核心；纤维增强须区别连续、短切、织物、纳米线网络；几何复杂或3D打印不自动表示材料复合。机制性工艺论文可以缺少直接介电测试，但必须有明确关联，并标“不能直接证明透波”。

现有综述9号Khatavkar在陶瓷范围下移出核心材料比较，保留跨体系参考；4号通用LLM仍非核心；6/8号保留测试可靠性辅助；5号炉衬是否核心取决于后续应用契约。属于写作用途调整，不需要删除已入库页。

筛选记录最低字段：稳定身份、来源检索批次、题名/摘要/全文筛选阶段、用途、纳入或排除理由、附件可用性、后续阅读问题。重复关系除DOI还要留意正式版/预印本、同一团队延续数据和综述共同转引；身份重复与实验数据重复分开处理。

检索日志记录数据库、日期、原样检索式、筛选限制、返回/去重/实际查看数量及前后向追溯来源。本次不补造历史检索式和漏失记录；原88篇仍称Zotero集合范围。优先补覆盖缺口、反例及能改变主线的论文，不能把新近年份或低ε作为唯一优先级。

## 5. 阅读规则：共同骨架加按需模块

新核心论文继续完整阅读方法、主要结果、讨论和结论，关键数字回查PDF。辅助文献可以限定阅读，但必须如实声明，不沿用“完整入库阅读”的措辞。旧页局部补字段不要求重新全文精读。

每篇先明确研究问题、实际样品组、对照变量和作者自称贡献，再提取证据，最后写可复用结论。新增以下领域模块；论文未研究的指标标“不适用”，不要造空白大表要求每篇填满。

| 模块 | 必须注意的记录 | 对应误用预防 |
|---|---|---|
| 材料身份 | 基体、增强体/形态、界面、添加物、残余相、组成基准wt%/vol%/摩尔比、密度/孔隙定义 | Al2O3纤维名称与实际含SiO2组成不能混同；不同孔隙定义不合并 |
| 工艺 | 关键变量、热历史/气氛、循环、取向/成型方式、最终样品状态 | 制备800 ℃不能写成测试800 ℃ |
| 电磁 | ε实/虚部、tanδ、频率、温度、测试方法、方向、厚度；透射/反射的定义、角度与极化（适用时） | 材料低损耗不等于给定构件高透射；实测与模型分开 |
| 力学 | 拉伸/弯曲/压缩、模量类别、韧性方法、几何/加载方向、温度气氛、样本量/误差 | 单纤维与复合体、弯曲与拉伸、位移与韧性不能互换 |
| 热学 | κ/热扩散率的区别、温区、方向、测试方法；CTE是区间平均还是局部定义 | 室温κ与高温耐受不能拼成高温κ；低κ并非所有应用唯一目标 |
| 环境/可靠性 | 氧化/热处理气氛、时间、热震介质与循环、前后测试状态、保留率分母 | 热处理后室温性能≠原位高温；一次水淬≠寿命 |
| 机制 | 直接表征、变化相关性、控制变量、替代解释、尺度 | XRD/TEM所见尺度不同；机制解释与已证实因果分开 |
| 模型 | 输入来源、几何、边界、频温区、拟合/验证集、实验验证范围 | 计算透射率、模型推导界面强度不能伪装为独立实测 |

正文与SI的阅读优先级由论断依赖决定：关键方法/核心数值只在SI时必须补读或暂不使用该论断；SI仅涉及本文不采用的次要结果，不阻断其余已核事实。视频“可变形”不能替代量化循环试验。

## 6. 记录规则：以样品和条件为单位

paper页继续作为科学证据权威来源，不另建一份含所有相同数值的长摘要。推荐增加精简样品映射和数据矩阵；样品标识在论文内稳定，不因后续排序改变。

一条定量记录的基本单位：**论文 + 样品/系列 + 指标 + 测试条件 + 来源定位**。同一E#可以包含数个明确区分的原始数据行；不为整理表格重编号E#。

建议数据字段分三组：

- 每行必需：record_id、paper/E#、sample_id或明确series、metric、原始值/范围、原单位、证据类型、测试状态、必要条件、source_locator、核查范围、未决影响、允许用途。
- 指标条件必需：随电磁/力学/热学模块启用；未报告必须明确NR，未核NV，不适用NA，三者不互换，更不能用0代替。
- 按需：统一单位值、换算式、估读精度、误差定义、独立来源组、模型参数和下游章节。原值始终保留，图估读不加虚假有效位数。

数据曲线保留覆盖范围与曲线指向；仅在支持比较所需时数字化，并记录方法/精度，不任意挑最高点或把温度区间与频率区间组合成完整二维实测网格。

示例：Jing论文ALA12的强度110.3 MPa、ALA6的断裂位移0.213 mm、ALA2的孔隙率13.5%必须是不同样品行，详见[[directions/wave-transparent-composites/wiki/papers/Jing-2025-Alumina-LaPO4-Interface]]；不能写成“该材料同时达到三项最优”。示例只引用既有页，不代表本轮重新实测或复核。

状态机制沿用hard_memory：processed是处理状态，draft/checked/needs-review是页面核查状态；每条E#另写实际核查范围和支持程度。需在方向扩展中澄清通用review_agent“draft内容准入”与局部已核E#的衔接：页面仍draft时，只有经明确局部复核、来源和适用条件充分、且不受该页未决影响的实验事实，才可按该范围进入事实矩阵；不能顺带提升机制或整页状态。该条是拟议澄清，本次不以此自动放行既有108条E#。关键论断存在争议的，留作争议/待核材料；全部主要证据达成所声明范围后才按既有规则升级页面。

所有值维持paper E#单一权威；矩阵是用于比较的派生视图，记录提取日期/版本并链接来源。更新E#后检查哪些比较行、章节句子受影响；不手工维护三份不关联的数字汇总。

## 7. 总结与综合规则

每篇末尾用一段约150—250字的可复用总结（长度是默认建议，不是硬门槛）：研究问题→关键设计→在何条件下得到何结果→主要代价/证据边界→可服务哪一论证问题。无需再另写重复摘要，不要求每篇都产出创新点或领域gap。

跨论文先建三种视图：

1. 覆盖地图：材料/增强结构×工艺×指标×环境，显示已覆盖、缺原始研究、缺SI或只有转引。用于安排阅读，不作为“领域没人做”的证据。
2. 性能比较视图：按样品和工况分组，标directly-comparable、qualitative-only或not-directly-comparable。不同温度、取向、频率、密度/孔隙、方法造成的差异先识别再决定能否排名。
3. 论证矩阵：一个待写判断，对应证据、独立来源、收益、代价、反例、适用边界、允许措辞和缺口。只保留服务本篇综述的问题。

比较分组建议：连续纤维承载、短纤维/颗粒多相、多孔隔热/纳米线、基体/界面参照分别组织；应用与测试条件是第二层筛选，不强行跨类综合打分。只有可比较数据足够时才考虑性能散点、Pareto前沿；不把缺条件的全部文献混画一条前沿，不设主观权重制造综合最优。

一条机制总结要回答“有什么证据、替代解释是什么、边界在哪里”；工艺收益同时列强度、韧性、介电、孔隙或制造代价中的实际变化。7号打印/CVI案例中韧性增加与弯曲强度下降应共同保留，见[[directions/wave-transparent-composites/wiki/papers/Wang-2024-VPP-CVI-Si3N4-Fibers]]。

同一实验经综述转引仍只计一个来源；同一团队不同研究不能自动并为一个来源，也不能因不同DOI自动认定数据独立。无法判定则标待核，不用于“多项独立研究一致证明”。

冲突记录按“原文位置→冲突内容→影响哪些判断→当前允许措辞→补核材料→处理状态”保存；数据争议只阻断相关论断。领域空白必须经过与范围一致的检索；当前文库没有只能写语料缺口。

## 8. 从证据到综述架构

优先试行的候选主线是“组成与结构设计如何实现透波—热力性能协同及其适用边界”。相较只按材料家族排列，它更适合串联目前纤维/界面、PIP、打印、多孔隔热与热震案例。但是否形成区别于已有综述的贡献，尚需对照既有综述的实际目录和论证完成验证。

先做已有综述对照表：范围/截止时间、章节逻辑、性能条件处理、是否区分实测与计算、机制/反例组织、未解决问题。本方向Zhou、Kenion、Nag、Xiang可作为优先对照；不能仅因它们未突出某词就断言存在综述空白。

以下是用于检验证据的候选结构，未生成正式综述大纲：

| 模块 | 要回答的问题 | 候选图表 | 达到可写状态的条件 |
|---|---|---|---|
| 范围与应用要求 | 本文讨论哪些陶瓷复合结构，评价目标为何不同？ | 材料/结构/用途分类图 | 工作契约与边界案例一致 |
| 测试与比较基础 | 低介电、低损耗与透射证据如何分别评价？ | 测试条件及证据类型表 | 关键术语有原始方法依据 |
| 组成、增强与界面 | 主要设计变量改变了什么，收益与代价是什么？ | 机制—证据矩阵 | 每条机制有定位和替代解释 |
| 工艺与微结构 | 工艺如何决定孔隙、界面、残余相和尺寸？ | 工艺→结构→性能关系图 | 箭头标测量关联/作者解释/假设 |
| 热力环境与多目标权衡 | 升温、氧化、热震等是否改变原有优势？ | 分工况性能图与退化路径 | 原位/热处理后/模型严格分列 |
| 构件和可靠性 | 试片到构件有哪些已验证/未验证环节？ | 证据层级与缺失环节表 | 有构件原始证据；不足则合并或缩短 |
| 结论与研究建议 | 哪些设计原则有条件成立，需要补什么验证？ | 问题—证据—验证路线表 | 反例与检索边界明确 |

材料家族作为章节中的比较维度和导航表，不在每章重复完整材料综述。若证据更支持“高温界面稳定性”或“多孔隔热透波”，可收窄主线；不预先强行扩成覆盖全部陶瓷和全部工况的大综述。

每节准备一张章节卡：问题、核心判断、证据行、反例/代价、拟用图表、与相邻章节的分工、缺失证据、ready/provisional/blocked。缺构件证据就缩短该节，不用通用展望填满。每段沿问题—判断—证据—限定—含义组织，原始研究支撑定量事实，综述用于背景与研究组织。

AI可辅助提取候选字段、发现冲突、生成待核措辞；数字、引用、模型/实测、证据独立性和结论边界必须回源。没有标注误差和独立校验，不把AI自动抽取表直接作为综述数据集。大模型专题只有真实陶瓷透波问题和足够原始证据时才扩展。

## 10. 分阶段实施与验收

| 阶段 | 操作与交付 | 验收门槛 |
|---|---|---|
| P0：边界及规则 | 以本方案生成工作契约和薄扩展，统一页级/证据级准入解释，AGENTS接入 | 陶瓷范围一致；不继承组内可做范围为综述上限；无重复公共定义 |
| P1：4篇试点 | 优先6/8/9/10号：样品错配、模型、气凝胶尺度、图文冲突 | 任一表格行可定位样品/条件/E#；冲突不被消失；计数不等于证据质量 |
| P2：增量迁移 | 扩展到当前与写作相关的17篇原始研究；9篇综述记录用途；非核心保持隔离 | 每篇有用途及阅读边界；不要求所有篇都进最终参考文献 |
| P3：缺口补文献 | 根据覆盖图补检索、反例、独立原始来源与必要SI | 每篇新增有明确问题贡献；检索过程可追溯；不能用固定篇数代替覆盖 |
| P4：主线与图表 | 既有综述对照、候选主线压力测试、章节卡及图表原型 | 删去最强单篇后仍能判断论证边界；所有图表可追源 |
| P5：分节写作 | 从证据成熟的章节开始，最后写摘要/结论 | 每个关键句有来源，模型不冒充实测，未知不冒充gap |

P1建议试点只填支持主要判断所需字段，并记录实际耗时与返工点；无实际用途的列删减。P2不要求一次重读27篇；已有证据充分则复用，缺的关键条件局部回查，核心未决再精读。P3以章节证据就绪和覆盖缺口收敛为停止条件，不以凑到某个参考文献数量为结束。

最优先工作：落实陶瓷范围与文章契约→试点样品/条件矩阵→据缺口补文献→比较主线→生成正式大纲。这样能避免继续大量入库后才发现章节缺少可比较证据。
