# B/C双轨方案完善与项目接入设计

## 1. 本轮结论与完成边界

采用用户2026-09-25的新目标：A退出当前候选，B与C并行验证证据，暂不确定主次，也不是同时正式撰写两篇综述。旧C优先、多尺度全链条方案转为历史设计参考，不能直接部署旧v2。

新方案的收窄是合理的：B按热历程组织结构—介电关系，C按界面/孔结构及其解释组织证据，两者共享事实但回答不同问题。当前最需要完善的是证据可配对性、论断级核查与迁移接口，而不是再扩目录。

本轮完整读取两份Markdown及Excel全部非空单元格、表头与验证配置，核对现有项目规则和指定写作参照笔记。来源清单及SHA256见[sources.json](sources.json)，模板实查见[template-audit.json](template-audit.json)。外部三个原件未修改。

本轮交付为方案与空白候选模板；已同步本方向当前目标及恢复入口，未批量复读、迁移27篇论文，未新增科学证据，未启用完整专用规则、提交或上传。本报告中的机制要求是阅读/判断设计，不是新确认的领域科学结论；未开展外部新颖性检索，不据此宣称B或C已经具备发表优势。

## 2. B：保留六章，明确“稳定性”的证据责任

工作题目保留《热暴露下陶瓷基透波复合材料的结构演化与介电稳定性》。核心问句是：**在何种热历程和测量状态下，哪些结构变化与何种介电变化相联系，这种联系能解释到什么程度？**

| 章节 | 应交付的判断 | 避免的重复或越界 |
|---|---|---|
| 1 引言 | 现有组织方式遗漏了什么状态/证据问题；本综述的对象与范围 | 不预先声称“从未有人研究” |
| 2 热暴露与材料状态定义 | 一张状态矩阵，统一热历程、测量温度、测量顺序和配对口径；简述检索/纳入边界 | 不扩成测试仪器大全 |
| 3 热诱导结构演化 | 哪些相、界面、缺陷、孔隙/裂纹变化被实际观察；哪些仅推测 | 只承诺结构端事实，不提前完整复述介电结论 |
| 4 结构相关介电响应与稳定性 | 用可配对证据连接第3章与介电变化；分原位、冷却后、循环/时间过程 | 不用未配对结构解释高温介电，也不把耐热温度当稳定性指标 |
| 5 机制解释与未决问题 | 对第4章关键关系比较解释、模型假设、反例和未排除变量 | 不把第3、4章重新按材料讲一遍 |
| 6 结论与展望 | 已成立的限定关系、不能回答的问题及最有判别力的下一步验证 | 不扩至完整服役可靠性 |

第4章名称先保留“响应与稳定性”，其内部是否分“可逆响应—残留变化—累积演化”由证据决定，不预设三个小节都有充分支持。第3章界面/缺陷与孔隙/裂纹不足时可合并。

**新增四条判断边界：**

1. 将制备热处理与后续热暴露分开。烧结/热解温度改变所得到的是不同初始材料，不能直接充当同一材料服役后的稳定性证据；它可用于形成结构的背景或C的工艺对照。
2. 分别记录暴露温度/时间/气氛/循环、介电测量温度/频率/方法，以及结构测量的时间点和状态。热后室温结构与原位高温介电不自动构成同状态配对。
3. “稳定”必须有比较基准、观察区间及变化量/不确定性。没有公认阈值时报告变化及作者采用的标准，不自定统一合格线。只有一个高温点或“较低损耗”，不能单独证明长期稳定。
4. 可逆性需要能对应的升降温/恢复过程；不可逆变化需要冷却后相对于基线的残留差异及误差限制。没有恢复测量就写“未检验可逆性”，不能从升温曲线直接判断不可逆。

若大多数资料只有温度相关介电数据，题目降为《陶瓷基透波复合材料的温度相关介电响应及结构关联》；若结构联系也稀少，则进一步减去结构机制承诺，而不是把“稳定性”改个名字继续保留同样强的结论。

## 3. C：保留七章，分开单因素、耦合和跨研究判断

工作题目保留《陶瓷基透波复合材料中界面与孔结构调控介电响应的机制》，但“机制”仍是待验证的标题承诺。

| 章节 | 应交付的判断 | 与相邻章节的分工 |
|---|---|---|
| 1 引言 | 为什么界面、孔结构值得作为共同问题；对象、范围及已有综述差异 | 不泛讲所有陶瓷透波材料 |
| 2 必要介电基础 | 后文真正用到的量、频率/状态限制和模型假设 | 原理、公式须核原始来源，不复用风格参考中的未核公式 |
| 3 界面相关介电响应 | 实际界面改变、对应介电现象和可支持的解释 | 每案例保留必要局部评价，但不反复展开所有竞争机制 |
| 4 孔结构相关介电响应 | 区分孔隙率/密度与形貌、连通、分布的证据贡献 | 相同孔隙率下的差异与共变系列分开，不宣称已普遍解耦 |
| 5 界面—孔结构共变及机制判别 | 跨论文比较最关键的归因问题，检查替代解释及实验/模型是否一致 | 以待判别问题组织，方法附着在问题上，不另写仪器或DFT清单 |
| 6 条件化机制框架与验证路线 | 从第3—5章提炼可使用的判断范围、失效条件和辨别实验 | 框架是综合产物，不再新增一轮未经核查的文献归纳 |
| 7 结论 | 用少量限定判断回答核心问题 | 不重复第6章完整展望 |

**不采用“相关→频谱→模拟→多尺度闭环”自动递增的质量等级。**这些是证据覆盖类型，不是普适排名。模型与实验共享拟合参数，或多个表征来自同一假设时，不能按方法数量计算独立验证；模拟图与实验趋势一致也不自动排除另一解释。

对每个机制问四个问题：实际改变了什么；在什么状态/频率下观察到什么；哪些结果能区分竞争解释；哪些变量尚未控制。缺少对应频率/状态与原始支持时，MWS、缺陷极化、局域场等保留为作者解释或候选机制，不能仅因术语常见写成事实。

透射作为有条件的下游后果：有对应实测或适用模型时写结果；只有介电数据时保留介电结论，不补造透波率。厚度、入射条件、频段和模型/实测身份不能省略。若界面证据不足而孔结构充分，允许缩为孔结构专题；不能只为题目对称而均分篇幅。若主要是关联，题目改为用户给出的“影响”或“结构—性能关系”。

## 4. 共用筛选规则：用途与相关度分别记录

对象仍是陶瓷基透波复合材料，不以本组已有材料名单限制外部综述覆盖。单相/多孔陶瓷可提供组成、孔结构或方法参照，但需要明确其在“复合材料”题目中的用途和边界；不因气孔被看成第二相就自动把所有多孔陶瓷升级为核心复合材料。

| 用途 | B判定 | C判定 |
|---|---|---|
| Core 核心 | 对热暴露—结构或结构—介电的关键关系有原始数据；不要求每篇完成全链 | 对实际界面/孔结构与介电响应的关系有原始数据；不要求每篇证明完整机制 |
| Context 背景 | 仅耐温、热力学/力学边界、结构演化背景或未配对高温数据 | 单相组成背景、结构/力学设计、没有相应介电数据的边界信息 |
| Method 方法 | 能帮助解决本题具体状态/测试/模型问题 | 能帮助判别本题机制、解耦变量或检验模型 |
| Review 综述 | 定位已有框架和追原始文献；不是独立原始验证 | 同左；写作风格来源与科学证据分开 |
| Exclude 排除 | 纯吸波/腐蚀/无明确热结构—介电用途 | 纯吸波/腐蚀/无明确界面孔结构—介电用途 |

`B_Relevance/C_Relevance`保留主题相关度，新增`B_Use/C_Use`表示论证用途。一篇可为B背景、C核心；`Primary_Track=Both`不能替代这一区分。Core表示值得深入处理，**不表示证据已核查或机制已成立**。同一论文只一个Paper_ID；同一可引用事实只一个Evidence_ID，Track=Both时两条线引用同一记录。

标题/摘要初筛可排除明显无关对象；边界论文检查必要正文后再决定。重复DOI、预印本与正式版、勘误、同组重复数据按身份和数据来源核对。缺全文可以登记候选及缺失影响，不能从摘要生成完整机制证据。

## 5. Excel模板审查及最小补强

原模板有三个数据表和Instructions；三个数据表均只有表头，**实际文献/证据/综合记录均为0**。1000行是预格式化范围，不是999篇文献。审查发现：

- Synthesis_Map只引用Paper_ID，不能直接指出支撑/限制某结论的Evidence_ID。
- Evidence_Records的Needs_Check缺逐条原因/实际核查范围；已读、直接性与支持程度容易混同。
- 同文对照未显式区分同样品、同批匹配、不同状态及无法判断；两篇文献不一定是两个独立数据来源。
- Evidence_Records验证范围至2000行，数据表至1000行；原验证未开启错误提示。开启提示有助于手工输入，但复制粘贴/程序写入仍须独立校验。

候选版本[BC_review_evidence_v2_candidate.xlsx](BC_review_evidence_v2_candidate.xlsx)保留全部原列及顺序、三个主表，不加入真实或虚构文献。新增字段与定义见[schema.json](schema.json)。字段按实际用途填写，不要求初筛时填完机制信息：

| 表 | 新增内容 | 何时必须填写 |
|---|---|---|
| Paper_Index | B_Use、C_Use；Zotero_Item_Key、Legacy_Wiki_Page、Source_Version；Verification_Scope | 正文纳入前明确用途；旧页迁移填映射；使用原始证据时说明来源版本；Verified须说明范围 |
| Evidence_Records | Evidence_Type、Verification_Status、Verification_Scope、Check_Reason、Pairing_Status、Data_Group_ID、Related_Evidence_IDs、Legacy_Evidence_Ref、Support_Assessment | 活跃证据须有类型/核查/支持判断；主张结构—介电关系时填配对和关联ID；疑点写原因；跨研究综合先判独立性 |
| Synthesis_Map | Supporting_Evidence_IDs、Limiting_Evidence_IDs、Comparability、Strength_Rationale、Readiness | 建立综合时填具体证据、可比范围、强度理由及能否用于当前表述 |

原有结构、介电、方法和作者解释列保留为上下文；一行应只有一个主要可引用断言。把观测与作者解释拆行时，不重复抄整套数据，而以Related_Evidence_IDs关联。配对状态针对本行断言；“同批匹配”不等于“同一试样”，也不等于已控制所有变量。

### 三个不能互相替代的维度

- **类型**：观察/测量、模型输出、作者解释、转引、AI推断，沿用公共证据标准。
- **核查**：Checked、Partial、Pending、Unavailable；核查范围具体写PDF图表/正文/SI及未决影响。它是单条证据状态，不替代论文页draft/checked/needs-review。
- **支持程度**：Sufficient、Partial、Insufficient，相对于Review_Usable_Claim且给理由。Direct仅指该断言的直接依据；结构和介电在同系列变化，可直接支持“关联”，不能因此直接支持某机制因果归因。

Paper_Index原有Read_Status继续表示处理阶段。Verified只表示注明范围已核，不能由某一条Checked推得整篇Verified；Needs_Check可为Yes并保留不受影响的已核结论。

Synthesis_Map的Strong/Moderate/Weak保留，但必须附理由：限定论断有相互支持且足够独立、条件可比的依据，且实质冲突得到处理，才可称Strong；关键适用条件或解释仍未区分写Moderate；主要是间接联系、转引或未解决核心冲突写Weak。不按论文数、期刊或仪器种类机械打分，也不要求所有论断都排除所有可能解释。

### 复核与写作准入

不影响当前句子的局部SI缺失可集中处理；身份、单位、样品、测试状态或趋势冲突若会改变当前论断，则先核查或隔离该论断。不得以“批量复核”允许未核关键数据先进入确定性综合。

`Readiness=Ready`表示**当前限定表述**可用：证据定位有效、必要范围已核、可比性已说明、关键未决不影响本句。Provisional可用于内部论证；Blocked不进入确定性正文。已核证据也可能不足以支持强机制主张；改弱句子后重新评价。

正式接入前仍遵守公共review_agent的准入规则。既有draft/needs-review不能靠复制到Excel、重取EV编号或手填Checked变成确定性依据。接入时须明确：BC证据集的声明范围、主要原文/映射核查、未决及直接下游处理均达到公共checked门槛，才能在对应限定范围替代paper E#作为写作接口；未完成该审核的迁移记录保持Pending/Partial与Provisional。旧页状态不因新库局部复核自动升级，旧来源状态及处理范围记入Verification_Scope。

建立Synthesis_Map沿用至少两篇论文共同回答问题的操作门槛，但另核是否共享数据，不能称“重复验证”。单篇限定实验事实仍可引用，可作为综合段中的实例；尚无跨论文问题时留在Evidence_Records，不为凑两篇制造比较。

正文由Synthesis_Map组织论点、Evidence_Records提供事实引用；必要原文复核始终允许。“只读一次”理解为一次面向B/C的整合阅读，不能作为禁止修正或补读关键材料的硬约束。

### 旧资料迁移的逐项交接

1. 先按DOI/条目身份分配唯一Paper_ID，记录现有paper完整路径；不按旧序号默认认定身份。
2. 从旧页定位相关E#，回到原文核查拟用于B/C的证据。旧页只作定位入口，不能因108条已有编号便全部视为可用事实。
3. 为新记录分配稳定的全库局部ID，例如P0001、EV000001、SYN-B-001；旧E1仍属旧paper，不重编号。Legacy_Evidence_Ref填写完整旧页及真实锚点；新证据拆分时允许多个EV映射同一旧E，合并时列全部来源。
4. 试点接受后，在旧paper页头加简短“当前BC维护入口/迁移范围”提示，不复制新数据；旧内容作为截至迁移日期的历史记录。未迁移部分仍按原页实际状态处理，禁止两个位置同时手改同一事实。
5. 如果迁移揭示旧结论错误，按原有纠错流程限定原结论及直接下游，再形成Excel修订，不用迁移掩盖错误。Excel撤回证据保留ID和说明，追查引用它的Synthesis_ID；不能删除行后复用编号。

迁移范围以逐条Legacy_Evidence_Ref和核查范围确定，不设“整篇迁移完成就等于整篇科学结论通过”。Excel是接入后BC工作的唯一维护事实源，旧页是可追溯档案；原始PDF仍是科学依据，不由Excel替代。

### 保存、版本与跨模型使用

当前仓库忽略xlsx；候选文件已在本地生成，但**不在Git版本备份范围内**。正式启用时先在本方向增加精确的忽略例外以跟踪该唯一工作簿；不全局开放附件、不自动上传外部PDF。采用单写入者，写前核对文件哈希、保存到临时文件并校验后替换，避免Excel人工编辑和模型覆盖冲突。

若后续需要文本差异审查，可从唯一工作簿生成带源文件哈希的只读CSV/JSON快照，不得手改快照形成第二事实源。本轮未建立额外运行数据库。schema及构建脚本是候选模板定义，不含文献事实。

给其他模型的批次包只需B/C综合行、其引用的证据行、关键Needs_Check、统计口径与目录版本；不再逐篇粘贴长摘要。模型返回的新判断必须回指证据ID，不能直接成为新事实。

## 7. 试点与最终选题门槛

建议第一批处理5篇有不同验证用途的已有论文：Cao 2013 SiNO/BN、Cao 2022 Si3N4f/SiNO、Li 2023 BN/SiON双界面、Meng 2023 PIP速率、Liu 2024多孔Si3N4。它们是流程试点候选，**尚未按新标准判为B/C核心**；名字只用于定位，实际身份以原页/DOI核对。需要补充B热循环/高温状态样本时，再定向选择，不把纯工艺热处理代替服役热暴露。

这批首先验证：同一论文能否一次提取服务两条线；样品/热状态能否正确配对；旧E#能否准确映射；作者机制解释会不会被误写为直接观察；是否出现重复维护；新增字段是否产生无用负担。5篇只验证流程和初步分布，不能代表全领域覆盖或据此确定B/C胜负。

随后整理已有核心候选，再针对影响核心链条的缺口补检索，同时追查最接近的综述及其覆盖截止时间。补检索保存数据库、日期、检索式和纳入/排除依据；未系统执行时不把文章称为系统综述。无需因原始集合无相关文献就宣称领域空白。

每批按去重Paper_ID统计B、C核心数及交集；B/C数可各含Both，但合计必须去重。Direct/Indirect等按证据行计，注明核查范围；结构—介电配对数按论文和有效配对分别报告，不能把两个无关联字段非空算配对。独立支持数按Data_Group_ID核对，未知独立性不计新增验证。

| 比较维度 | B需要回答 | C需要回答 |
|---|---|---|
| 关键链条 | 热暴露、结构状态和介电测量之间能连到哪里 | 实际界面/孔结构、介电现象和候选解释之间能连到哪里 |
| 核心困难 | 同状态配对、恢复过程、时间/循环及测量差异 | 变量解耦、竞争解释、模型适用条件 |
| 论证价值 | 比材料耐温表新增了哪些可支持的稳定性判断 | 比孔隙率—介电趋势图新增了哪些可支持的解释 |
| 与已有综述差别 | 是否只是改标题重排相同案例 | 是否只是给常规作者解释换上机制分类 |
| 处置 | 保留主线/缩小热状态或材料范围/退为背景 | 保留双因素/收窄单因素/将机制降为关系 |

不预设固定总篇数即可成稿，也不以打分小数判定发表前景。只有核心章节能形成可追溯、有边界的综合判断，主要断点得到处理且与已有综述有明确差异时，才固定目录并进入写作；若两线都不满足，继续缩题。

## 8. 写作规范及实施顺序
