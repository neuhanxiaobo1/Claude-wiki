# 语料与筛选规则草案

本文件为未启用草案，拟部署到本方向memory/corpus_rules.md。只补充公共import_zotero流程，不改变原件、去重、稳定编号或Zotero写入授权。

## C-01 目标与用途

当前综述工作主线固定为C：组成/实际结构—介电响应—电磁传输的机制与证据联系；具体题目及应用边界可随证据收窄。不得回到A/B排序或以本组可做范围限制综述覆盖。任何新候选先回答“它服务C的什么问题”，不凭关键词或作者单位决定纳入。

为文献记录一个主要用途，可注明次要用途：核心陶瓷复合体、组分/基体参照、物理/测试/模型方法、跨体系背景、写作参照、范围外档案。用途属于本篇综述而不是对论文质量的评级；用途调整不自动删除条目或重做入库。

同时记录其实际贡献环节：组成/结构表征、介电响应、传输评价、环节连接、边界/反例；允许多项，不要求全链。初筛未知则标待全文判断，不能以无摘要或无机制关键词直接排除。

## C-02 材料身份边界

核心材料要说明实际基体/骨架、增强体/第二相、界面或层级结构；不能仅凭多元素、PDC、多孔或3D打印认定是复合材料。单相陶瓷、单体PDC及独立纤维可作关键机制参照，迁移到复合体时要说明未验证部分。

树脂基写作参照不能自动加入陶瓷核心数据表。纯吸波、纯腐蚀只有存在明确相关问题才作有限方法背景，不能用吸收增强证明透波改善。缺透射测试不自动排除：介电或结构实验仍能支撑链条局部，但不得声称已测透射。

## C-03 最小筛选记录

在已有manifest/清单中增量补用途与理由，不另建同内容清单。最低记录：稳定身份；来源批次；已查看到题名/摘要/全文哪一步；用途；贡献环节；纳入/待核/不进入当前综述的理由；附件缺失及影响。正文深读、机制核查和写作准入不是初筛通过的同义词。

检索日志记录数据库或集合、日期、完整检索式与限制、实际返回/去重/查看范围；未保存的历史条件不得重造。现有88篇是集合范围，不能称系统检索结果全集。

## C-04 下一篇选择原则

优先解决当前章节最关键的证据断点、竞争解释、原始转引和模型验证，兼顾材料/团队/方法代表性。优先级理由写清，不设机械综合分数或凑篇数目标。有严格对照的纯实验论文不能因无DFT降级；有复杂计算不自动升级。

阶段停止点：当前问题已有足够支撑允许的判断，或继续读取同类来源不再改变判断但仍缺其他证据。后一情况应换检索方向/收窄论断，不称全领域无解。论文没有测量≠本库缺口≠领域空白。

## 交付门槛

身份和用途可追溯；材料归属明确或待核；贡献与不能支持的范围已写明；清单/manifest处理状态一致。未进入核心语料者保留合理档案用途，不自动删除。
