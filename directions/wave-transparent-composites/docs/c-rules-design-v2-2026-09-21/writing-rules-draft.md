# 综述写作与表达规则草案

本文件为未启用草案，拟部署到本方向memory/writing_rules.md。使用公共review_agent和review模板；本文件补充C目标及用户指定写作参照，不替代证据准入。

## W-01 写作参照和目标

指定参照为Nature Reviews Bioengineering 2024社论及Tang等2021树脂基透波综述，身份与已读范围见[[directions/wave-transparent-composites/docs/c-oriented-rules-2026-09-21/style-reference-notes]]。首轮写作查该阅读笔记，涉及具体原句/公式/细节再回源；无需每次重读两篇。

学习问题视角、概念铺垫、对照叙述、图表解释和具体展望。不得照搬段落/独特句式、引用排序、图形布局，或把树脂机理直接迁移为陶瓷结论。所谓风格和水平，以论证清楚、证据相称、表达简明及新的综合理解评价，不以术语密度或期刊口吻评价。

## W-02 工作契约与章节

profile记录已确定C工作主线、材料范围和参照；一份工作契约（建于开始实质写作时）记录该稿研究问题、检索截止、实际语料、输出语言/篇幅及当前题目边界。用户未固定项标待定，不为启动证据整理强制逐项询问。

C是研究问题，不是已证实结论。材料、尺度和方法只作服务问题的组织维度，不强制固定七章或八章。模型与实验放在它们回答的问题中，避免同一机制在尺度、仪器和计算章节重复。A的力学权衡/B的环境演化只作为C论证需要的约束。

每章准备：问题、中心判断、证据矩阵行、必要背景、比较/反例、图表任务、允许措辞、缺口及公共ready/provisional/blocked状态。没有ready章节也可交付暂定框架，但不能写成证据充分的定论。

## W-03 段落与措辞

段落围绕一个判断展开，连接代表性证据、条件差异及含义；作者姓名是引用定位，不作为连续段落的唯一组织轴。先在自己的论证笔记中完成比较，再独立成文。

实测写测得/观察到；作者解释注明归因主体；部分支持写一致性与未排除因素；综述推断说明组合依据；假说说明需验证。用词由证据决定，不机械套固定句式，也不为了谨慎把全部事实弱化为可能。

首次解释关键术语，保持符号、量及单位一致。首次/最佳/普适需检索，显著需统计，协同需明确多指标同对象对照；不允许用低ε替代高透射或用耐温替代功能保持。

## W-04 图表和公式

图表必须承担比较、解释连接、展示反例或界定范围的一项具体任务；优先原创概念图及可追溯比较表。示意箭头区分测量支持/模型/假设，不能把假设画成已验证过程。

数值图注明样品、频温和实测/模型；不同条件不画统一排名、拟合或Pareto前沿。同源重复点不制造证据密度。

仅对正文实际使用的关键公式记录出处、符号/量纲与约定、假设、适用条件和验证。T、R、A、S参数及其幅值/功率定义以来源与实验配置核对；发现来源符号疑点时暂停该式依赖的推导，不擅改原文，不阻断无关章节。不先建设大型公式库。

## W-05 总结与展望

结论回答读者现在知道什么、凭什么知道、成立范围和关键例外；不复述全目录。展望从真实缺口提出对象、可区分的解释、所需观测/对照、模型输入与验证方式；不泛列多功能/智能化。

LLM辅助抽取、组织和语言编辑，不提供物理真值。数据驱动若无与主线相称的原始证据，仅作为限定方法讨论；不因用户历史兴趣强制独立成章。

## 交付门槛

沿公共写作准入；关键句可回到实际支持的E#或claim；章节职责不重复；实测/模型/解释明确；两篇参照用于提升逻辑而非复制；未决紧邻受影响判断；完整性和风格分别验收，不能互相抵消。
