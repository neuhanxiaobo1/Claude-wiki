# C主线综合与比较规则草案

本文件为未启用草案，拟部署到本方向memory/synthesis_rules.md。与公共synthesis_agent、gap_agent组合，沿用已有支持程度及可比性术语，不引入新的质量等级。

## S-01 以问题建矩阵，不先写证明性结论

每轮明确一个待判断问题以及实际语料。一个派生矩阵的最小列为：判断/问题、paper E#、贡献环节、样品与关键条件、独立来源、支持程度/核查范围、比较资格、替代解释/缺口、允许用途。

覆盖图、性能比较和机制论证是这份记录的按需视图，不强制维护三份平行数据表。paper的E#是源证据；矩阵只是跨文献组织，不在复制时改值或升级状态。

## S-02 跨尺度连接的成立条件

连接两个环节前说明：上游提供什么量/关系，下游需要什么输入，中间的假设、单位/方向/频温条件以及验证范围。结构图+电子结构图+传输曲线并列不能自动称多尺度耦合。

不同论文连接可以形成综述推断，但要声明条件匹配程度及未验证接口。无法连接的局部证据依然保留，不画成完整已验证闭环。

## S-03 可比性、独立性与反例

按公共directly-comparable / qualitative-only / not-directly-comparable逐组判断。尤其核对频率、温度、测量方法、厚度/取向、密度/孔隙、相组成、热/湿历史及模型边界；不是每个条件不同都必然不可比，须解释差异会否改变当前判断。

同文对照优先，但同文也可能变量混杂；不同团队不自动独立，同一团队也不自动同源。综述转引与原研究不能多计；同一实验供拟合和验证不能描述为独立预测检验。

主动查找限制当前解释的反例与负结果；没有找到时记录查找范围，不虚构反例，不强制每段一正一反。冲突依次核定义、条件、身份、方法、来源独立性和证据层级，再判为条件差异/未决冲突，不能用平均值抹平。

## S-04 从局部事实到设计认识

分开输出：限定结果、作者解释、本综述综合判断、待验证假说。单篇能支持限定事实，不强制多篇；一般性设计原则的证据覆盖必须与外推范围相称。

设计认识写成“在条件X下，证据支持关系Y；当Z变化时尚不确定/出现例外”。不把降低某介电指标、提高某力学指标、改变某结构合称全面协同。

## S-05 写作交接与来源修订

矩阵进入正文前按agents/review_agent第2节准入，不新增免核快捷路径。draft/needs-review/争议内容不得经本矩阵变成确定性结论；确定性核心论据不足时，先选涉及的最小原始证据做复核，或输出明确暂定的问题框架。

不为解锁写作批量升27页checked，不将draft证据复制到新claim再改状态规避核查。已有局部已核的事实保持实际记录，其准入范围不能由当前方向私自放宽公共规则。

证据修订只检查明确依赖的矩阵行、图和章节；在影响记录写具体对象与判断，不重复复制所有日志。核心前提失效时收窄主线，不只添加免责语。

## 交付门槛

每个主要综合判断有适用范围、支持来源、比较资格、独立性及边界；跨尺度接口有说明；准入状态无静默升级；下一步补读由最关键缺口驱动。
