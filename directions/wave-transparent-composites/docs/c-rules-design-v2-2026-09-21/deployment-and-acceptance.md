## 2. profile和短状态整理

profile收敛为五段：当前C目标；材料/应用边界；两篇指定参照；文献来源入口；未定的具体题目与工况。前期组内选题和大模型探索压缩为历史背景，引用历史决定，不删历史、不混作当前强制任务。

current_context只保留当前任务、已经完成的边界、最新交付、下一步/阻塞和版本发布范围。旧入库详细过程保留log和报告，避免恢复时误把“等待第三方案”“规则尚未形成”当当前状态。

术语表先不增设完整分类系统。在实际比较出现歧义时登记：材料名称与实际组成、ε′/ε″/tanδ的使用约定、透射幅值/功率、温度处理状态、基体/复合体、直接测量/反演/计算；每条有适用说明，不能把不同量或不同材料作为同义词合并。

## 3. 最小工作契约内容

实质写作开始时建立一份，不与profile重复保存全部配置。起始内容可为：

- 工作问题：组成和实际结构变化如何影响介电响应，以及在什么条件下能连接到电磁传输？
- 范围：陶瓷基复合体为主；组分/单相/单体PDC按用途作参照，树脂基及写作方法另标角色。
- 不预设：某机制必然主导、所有尺度已连通、全部低ε材料均高透射、特定航空工况或全温频覆盖。
- 实际语料与截止：使用时登记，不能用库内篇数替代完整性声明。
- 预期产出：证据矩阵支持的主线与章节；直接测量、模型和作者解释明确。
- 收窄条件：核心章节的联系只能靠一般理论或推测连接时，改为结构—介电响应关系或更窄对象。
- 题目、投稿期刊、字数：尚未定不阻断规则实施和证据整理。

## 4. 旧27页的迁移顺序

先按关键论证依赖，处理5篇试点；不是按引用数、发表年份或‘高水平期刊’排序。每篇只补影响C用途的条件、贡献环节及机制边界。与正文无关的现有正确内容保留，原始证据编号不变。

后续分为：当前关键判断依赖、可作辅助/反例、暂不使用三组。第一组按需原文复核；第二组保持明确用途；第三组保留档案不重读。该分组是任务优先级，不新增永久科学质量标签。

如果一篇现有主要结论仍有未决，依公共状态定义保留draft；可以继续形成有状态的比较记录和暂定章节，不为赶写作制造checked。

## 5. 实施验收清单及失败处理

| 检查 | 通过证据 | 失败时做什么 |
|---|---|---|
| 范围 | 变更清单全部位于当前方向；公共/其他方向无新修改 | 停止越界写入，保留本轮合法产出 |
| 路由 | 扩展文件真实存在，AGENTS按任务指向它们 | 修正路径/遗漏，不用状态文字代替部署 |
| 状态 | 草案和生效文件区分；没有将旧页批量升级 | 撤去自动升级，回具体证据核查 |
| 源事实 | 试点E#保持ID，重复数字不新增权威副本 | 合并派生重复值为引用，保留原始定位 |
| 条件 | 样品/频温/模型边界影响判断时有记录 | 限制相关比较，继续不受影响部分 |
| 机制 | 观察/解释/模型/综合判断可分辨 | 降低或拆开论断，列所缺区分证据 |
| 风格 | 试写围绕问题比较，有条件/边界，独立措辞 | 重写论证顺序，不能只换同义词 |
| 原件与版本 | 用户文件/PDF/缓存未改，发布范围如实说明 | 查明误写范围，按明确恢复依据处理 |
| 负担 | 每个新增字段实际服务身份/比较/判断/追溯之一 | 移除无用途可选字段，不以删掉必要核查减负 |
| 恢复 | 中断后可从短状态确认已部署文件、完成论文及未决 | 补必要交接，不重跑全部入库 |

试点可以用记录完整性与返工点判断规则有效性；本轮没有测得耗时，不声称节省百分比。结构脚本和链接检查只证明对应结构检查通过，不证明科学结论或写作质量通过。

## 6. 发布和版本边界

本设计定稿是‘可部署候选’，不是已通过实际阅读试点的最优规则。部署时保留当前草案作设计依据；试点证实需调整则改对应条款并记原因。旧设计报告保留历史，不再作为独立生效规则层。
