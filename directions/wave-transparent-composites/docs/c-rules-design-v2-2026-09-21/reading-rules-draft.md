# 阅读与证据记录规则草案

本文件为未启用草案，拟部署到本方向memory/reading_rules.md。沿用pdf_read_agent的新入库、完整复核、局部修订模式及实际阅读覆盖要求；不以字段精简降低主要方法/结果/图表阅读范围。

## R-01 六项最小记录

每条主要E#保留：①样品/对象和对照；②实际观察/测量/计算；③必要条件；④原文位置；⑤支持的判断和未决；⑥在C链条中的贡献。前五项已有则只补缺项，不重写，不重新编号。

把设计操作、实际结构、物理过程、模型方法分开。原始数值只在E#或其关联数据行保存一次；结论、矩阵和章节引用它。NR未报告、NV未核、NA不适用可用中文表述，不强制缩写，更不能用0替代缺失。

## R-02 按论断触发条件模块

| 触发 | 必须核对的条件 | 不触发时 |
|---|---|---|
| 介电结果进入比较 | 量及定义、频率/温度实际测点、方法、样品方向/状态；密度/孔隙按比较需要 | 不造介电数值 |
| 使用透射/反射/吸收 | 实测/模型/转引、功率或幅值定义、频率、厚度、角度/极化、结构和归一化/边界 | 不要求只有力学的参照论文填写S参数 |
| 因果或机制解释 | 结构变化证据、对照、混杂、候选过程适用频温区、替代解释及区分所需证据 | 可仅作性能/结构事实记录 |
| DFT或其他原子计算 | 实际输出与响应分量、方法假设、对象/频域、与实验连接方式 | 不强制每篇有原子尺度解释 |
| 有效介质或场模拟 | 参数来源、相形态/体积分数、尺度和几何假设、边界、验证与拟合关系 | 不把缺模型当劣质证据 |
| 热、力学或环境影响机制判断 | 处理与测试时状态、气氛/时间/方向、指标定义及保留率基准 | 仅列与C问题有关的约束 |
| ML/高通量或LLM | 数据来源、目标、分组独立性、验证/外推范围；LLM输出的回源核查 | 不强制智能章节 |

缺失条件只阻断依赖该条件的比较或论断；继续记录其余可核部分。SI中关键方法/数值影响主要论断时才必须补核；未获得就明确限制该论断，不能把所有SI缺失变成整篇阅读阻塞。

## R-03 机制解释的五问

观察与作者解释分开。逐项问：实际变量改变了什么？证据测到了什么？候选过程在目标条件下如何被支持？还有什么共同变化或替代解释？新增什么观察可区分解释？

不由界面图证明界面极化，不由push-in力学数据替代电磁过程，不由DOS/CDD/ELF直接得完整GHz复介电响应，不把介电降低等同于指定构件高透射。也不反向宣称这些方法无价值：只限定它们支持的环节。

作者没有机制研究时不强行替作者补机制；有合理解释但证据有限时保留为解释，不要求先排除所有可能性才能记录结果。

## R-04 单篇总结及模板边界

Conclusions for Reuse回答“本篇对C最有价值的结果/解释、条件与限制、服务什么问题”；通常一小段即可，不硬设字数。若有待比较的机制，在该栏目用本目录mechanism-record-template的最小形式追加；不要再建立一份数值相同的独立卡片。

原文冲突双方保留位置，不能合并为数值区间；关键图表/OCR/公式问题按公共流程回PDF，证据变更检查直接下游。局部修订不要求补齐整篇模板，也不把局部已核变成整页checked。
