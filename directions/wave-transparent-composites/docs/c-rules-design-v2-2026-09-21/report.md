# C目标方向专有规则设计 v2：审计、条款与部署方案

## 本轮结论与完成边界

当前目标方向确定为陶瓷基透波复合材料的C主线：多尺度介电响应与电磁波传输。最终题目、频温区及章节承诺仍须与证据匹配，不再次讨论选A还是B。本轮重点是把目标变成任务可调用的方向规则。

已读取实际生效的方向AGENTS、profile、短状态、词表，重新核对公共hard_memory、pdf_read、synthesis、review流程，并与此前C方案比对。结论：公共科学证据底线已充分，当前缺的是方向任务路由、C专用的按需记录、阶段交接及统一输出职责。应新增四个薄扩展和一个轻量模板，不改公共流程，不一次性重构现有论文页。

本轮已形成五份可直接审阅的文件级条款草案，而非只列未来工作。草案保存在docs，状态proposed；尚未部署到memory/templates或接入AGENTS。因为当前请求是设计完善方案，本轮交付的完成标准是条款、路由、迁移与验收可执行，不声称规则已生效。未重读原始论文、未改科学结论或review_status、未新建paper/claim、未上传。

## 设计收尾

本轮续办已补齐[AGENTS完整接入正文、工作契约要点、旧页迁移和实施验收](deployment-and-acceptance.md)。当前设计包已完成，后续剩余是部署和真实试点，不再属于尚未写完的方案。‘更优’指职责清楚、按需加载、避免重复并能通过实际案例检验，未作未经试点的最优性/效率保证。

## 2. 稳定规则与可变研究对象分离

- profile只存已确定目标、边界及用户偏好。当前C是工作主线，不是已证明所有尺度机制都能连通。
- 专项规则定义遇到某种任务该怎么读、记、比、写，不写固定科学答案或最终章节目录。
- 工作契约在开始实质写作时建立一份，记录当前题目、问题、语料截止与章节承诺；调整题目不必改四份规则。
- paper E#保存源证据；机制摘要放原页，跨论文矩阵保存比较关系；review保存章节和正文。不另建重复科学事实权威。
- current_context只保存当前阶段、完成边界、下一动作、阻塞及恢复链接；不堆全部历史进度。log保留历史。
- 两篇指定写作参照笔记是风格设计依据；其原文事实/公式仍按科学证据核查，不享有免核待遇。

这套分工使规则长期可复用，同时允许C在证据不足时收窄成结构—介电响应关系，不必推倒知识库。

## 4. 阶段准入：入库不等于可写

| 阶段 | 需要做到 | 能交付 | 不允许越级 |
|---|---|---|---|
| 候选筛选 | 身份、初步用途与实际查看范围 | 推荐/待核/不纳当前综述的理由 | 未读全文不能宣称机制成立 |
| 阅读入库 | 主要方法/结果覆盖、E#、条件及边界 | processed论文页，可仍draft | 入库数不能当可靠证据数 |
| 比较综合 | 独立来源、条件可比性、支持与替代解释 | 暂定/限定综合及待补证据 | 不可比数据不能形成统一排名 |
| 主线验证 | 核心判断与证据匹配，主要依赖和反例明确 | 有条件的大纲/章节状态 | 不能为了保C标题补全无证据链 |
| 正文写作 | 遵守公共review证据准入 | 准入范围内的事实及明确限定的争议讨论 | draft内容不得静默变成确定结论 |

‘局部证据已核’不自动升级整页；‘页已checked’也不自动使每个机制有充分支持。核查范围与支持程度继续分开。当前27页/108条E#不在本轮一揽子评判，正式写作时按关键判断依赖排序复核。

## 5. 防止规则过重的明确设计

1. 六项最小记录是现有E#的整理，不是六份新表。条件模块按当前论断触发，不要求只有力学的辅助文献填写透射几何。
2. 机制记录优先嵌入现有总结，只有跨文献多次复用且关系明确才建立claim，不强制每篇产出gap。
3. 覆盖图、性能比较、机制图可从一个最小矩阵派生，避免手工复制三份数字。
4. SI缺失只限制依赖它的判断，不要求未使用的附件全部读完；重要机制依赖SI时则不能绕过。
5. 不设固定篇数、统一机制评分或所有文章全链闭环要求。不存在必须先有所有字段才能继续的前置障碍。
6. 不新增数据库/同步服务，不改变raw或Zotero原件，不要求先把旧27页全部套新格式。
7. 删去无实际用途的字段，以试点实际产出和返工问题决定增补，不能凭规则更长判断质量提高。

## 6. 用现有案例对草案作桌面验收

以下是基于既有知识页的规则情景推演，不是新一轮原文复核或科学测试；它检查条款是否给出正确处理路径。

| 情景 | 要求的处理 | 对应条款 | 设计核对 |
|---|---|---|---|
| 稀土单相陶瓷有DFT/CDD | 作为组分参照，限定输出，不能自动证明复合体GHz机制 | C-02、R-02/03、S-02 | 有明确路径 |
| Meng速率、碳与孔隙同时变 | 保留同文测量及作者解释，不独立归因孔隙或残碳 | R-03、S-03 | 不为配主线强行归因 |
| Chen push-in界面数据 | 支持机械界面行为，不能替代界面极化证据 | R-03 | 不混淆跨指标证据 |
| Jing多个样品最优 | 各样品单独记录，不拼综合最优；计算透射单列 | R-01/02、S-04 | 样品身份约束充分 |
| Yu透射公式有疑点 | 暂停该公式依赖的推导，不抹去可用介电测量 | R-02、W-04 | 不整篇阻塞也不默许模型 |
| 气凝胶室温κ与高温介电 | 分开条件与样品，不合成高温κ或承载性能 | R-02、S-03 | 条件比较有入口 |
| 缺SI但只影响碳含量 | 该项保持未核，其余独立证据继续使用适用状态 | R-02、S-05 | 缺失影响局部化 |
| 原文draft且正文想引用 | 不批量升级、不洗成新claim；按公共准入复核或限定用途 | S-05、阶段准入表 | 消除前稿准入歧义 |
| 参照文章出现可疑公式 | 学组织与表达，公式另核，不继承其权威 | W-01/04 | 风格与科学分离 |
| 新论文只有可靠性能对照 | 可以贡献边界，不强制制造机制或拒绝入库 | C-04、R-04 | 不偏爱复杂计算论文 |

正式部署后的5篇试点沿用前版对象，但交付改为：原页必要增量＋一份最小矩阵＋规则负担反馈，不再额外建5个重复卡片文件。试点验收检查身份/条件、链条贡献、模型边界、替代解释、引用追溯和实际工作负担；本轮未宣称试点执行完成。

## 7. 增量实施、验收和回退

1. 部署前记录拟改文件的版本/哈希，确认无并行漂移；只动本方向。把四草案定稿部署到memory和一模板到本方向templates，再一次接入AGENTS，不先写无目标链接。
2. 整理profile的当前C契约与历史选题背景，current_context只保短交接。不重命名方向ID，不改变另外两方向或根公共规则。
3. 对既有5篇做按论断的试点，保持路径/E#稳定；发现原结论错误才按证据修订规则改，而不是为新格式全文覆盖。
4. 以试点发现调整规则，逐步迁移真正进入综述论证的论文；范围外和纯方法档案无需全面重读。
5. 在需要写作的核心句上执行原文/状态复核，再开展首个试写小节；风格与科学准入分别检查。
6. 验收包括方向结构检查、规则链接、禁止跨目录写入核对、上述情景覆盖及人工证据评估。结构脚本只能查结构，不宣称已验证物理解释。
7. 若试点负担明显大于收益，先去掉无用可选字段，必要时撤回AGENTS的新路由并保留已核证据；不删除paper、恢复原件或整库reset。未解决规则不能自动复制至别的方向。

本轮仅进行了草案链接/格式及现行方向结构检查，部署、原文复核、试写和回退演练均未执行。后续以实际结果更新，不预记通过。
