# B/C领域证据契约

配合[[directions/wave-transparent-composites/rules/bc-review-workflow]]使用；本页只规定陶瓷透波综述的判断边界，不复制公共证据标准或Excel全部字段。记录位置见[字段schema](bc-evidence.schema.json)。当前版本经第二批五篇实际阅读后启用。

## 材料对象与用途

| 实际对象 | 记录与准入 |
|---|---|
| 连续/短纤维、晶须、颗粒增强或多相陶瓷复合体 | Composite_Type写实际增强体、基体、界面及构成；按B/C问题独立判断Core/Context，不要求都为连续纤维 |
| 夹层、梯度或多孔复合体 | 记录材料层和构件层；宏观壳/芯界面与微观界面分开，不能由层厚效应推出界面极化 |
| 单相多孔陶瓷、PDC块体/纤维 | 默认Context/Method；写明是组成、基体或结构参照。若改变核心对象范围，须在profile/决定记录说明，不能为增加核心计数静默升级 |
| 树脂、纯吸波、纯腐蚀 | 不进入陶瓷透波核心性能比较。相关方法另标用途；吸波应用论文中确有低损耗基体研究时允许定向Context，不以题名一刀切 |

Core指直接服务某个综述问题，不是质量认证，也不表示本文证明了题目中的机制。材料来源不因Zotero目录名称而变为“组内成果”。

## 状态与对应关系

Thermal_State使用清楚文字说明：制备态 / 原位升温 / 原位降温 / 热处理后冷却 / 氧化后 / 循环后 / 未明。Intervention_or_Condition记录暴露温度、时长、气氛、循环及必要升降温；Dielectric_Test_Condition单独记录测试温度、频率、方法、取向、尺寸、预处理和均值/单点口径。NR不补猜成室温。

对应关系分三层，不能混作一个通过/不通过开关：

1. **同条件系列**：有一致配方与明确处理标签，可以逐条件并列结构和介电；在Sample_or_Group写清标签，Related_Evidence_IDs连接。
2. **同批匹配/同试样**：来源明确说明才填Matched-batch/Same-specimen；同论文、同温度、近似密度不充分。Unclear保留第1层信息，不等于完全不能综合。
3. **机制连接**：还须控制竞争变量，检验观察尺度、时间/空间范围和模型。前两层存在不自动证明因果；局部显微图不代表整体响应。

统计“有效配对”必须声明是哪一层。制备热解次数不能算服役热循环；制备温度不算介电测量上限。热后一次测量不能证明可逆性，质量随时间曲线不能代替介电随时间曲线。只有升降温/恢复或循环响应及结构证据允许讨论对应范围的可逆、累积与稳定。

## 介电、传输与模型

| 关键问题 | 必须检查；记录在既有EV字段 |
|---|---|
| ε′、ε″、tanδ | 保留量的定义及无量纲属性；tanδ=ε″/ε′只在同状态、同频点/一致平均口径下核算。结论误把ε″写为tanδ时保留冲突，不能静默纠正原文 |
| 频段与温度 | 方法段、轴标、图注、表和摘要互核；范围冲突限制定量比较。仪器型号和量程疑点需要原始方法/官方资料，不能凭型号猜单位 |
| 透射T、S21、R/A | 说明幅值还是功率、归一化/端口条件、厚度、角度、极化、频率与状态。低ε′不是高透射的充分条件，窄带介电测量不能充当宽带透射实测 |
| 解析/有效介质/EM模型 | 单独标Model-output，记录输入来源、几何/尺度、组分、孔模型、边界和验证范围；不因拟合良好排除其他机制。模型中的常数不能替代同状态实测 |
| 计算热震或综合指标 | 记录公式/假设/来源；不得算热震实验或构件可靠性验证。强度保持率核算结果与作者报告分别标明，基线不一致先隔离 |
| 图片与OCR | 凡单位、下标、方向或关键点决定判断，回查PDF原图；注明估读范围，不给伪精确值。图中“约”与正文均值不是同一个全频上限 |

源类型无法判定先用Unclassified-report；这是临时隔离类别，不是第六种科学证据，也不是弱机制等级。确认来源后保留EV并记类型修订。SI若决定模型输入或主结论，只阻断依赖它的论断，其余观察仍可入库。

## B/C机制评价与反证

- B按热状态连接相/化学、界面/缺陷、孔/微裂纹与介电。XRD无明显新峰仅限检测尺度；不能推为界面/化学完全不变。氧化后损耗降低不等于未发生退化，更不能把机械保持率替作介电保持率。
- C先列实际变化的界面、孔及同时变化的组成、残碳、吸湿、密度、批次。开孔率/总孔隙率、孔径/孔喉、形貌/连通性不同；SEM形貌不自动给连通性，XRD相对峰强比例不等于绝对体积分数。
- 界面极化/MWS、局域场、导电损耗等解释须处于对应温频及材料状态。机制支持写“观察关联→模型相容→可区分竞争解释的证据”，不按仪器种数打分，也不强制所有论文补齐全部链条。
- 力学界面结合增强不能作为电学极化的直接证明；宏观层结构传播设计不能自动解释微观界面电荷。
- 每个机制综合记录至少一个实际竞争解释、现有排除证据或未排除原因。没有反例时说明检索/语料范围，不制造反例；同团队或相同制备平台的数据独立性未核时，不按论文数宣称重复验证。

## 写作与收窄

沿[[directions/wave-transparent-composites/docs/c-oriented-rules-2026-09-21/style-reference-notes]]的已读范围借鉴问题组织、批判性比较与明确表达。正文按“限定判断→证据→差异/反例→解释→适用边界”组织；不复制原文表达或段落结构，不把树脂机理移植到陶瓷。

B缺少可配对的结构变化/介电恢复时，将“稳定性机制”收窄为“温度相关或热后介电响应”；C只有孔隙率/组成关联而无可区分解释时，将“机制”收窄为“结构—介电关系”。目录状态只针对该节限定问题，单条Ready不代表整章、主线或全篇Ready。
