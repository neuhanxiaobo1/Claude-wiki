### CMAS 领域阅读辅助项

仅用于相关论文，并按本轮论断选择适用项；不是每篇必填矩阵。公共证据标准仍以 `memory/hard_memory.md` 为准。原文未报告的关键条件标为待核查或未报告，不推测补齐；不影响本轮判断的非适用项可以省略。

| 关注点 | 核对内容 |
|---|---|
| 材料与样品 | 化学组成、相结构、制备方式；块体、粉体或涂层及孔隙/几何差异 |
| CMAS 与接触方式 | 配方及质量/摩尔分数基准、用量/负载、铺粉或混合等接触配置 |
| 暴露条件 | 温度、时间、气氛、热历程；原位观察与冷却后表征的区别 |
| 反应与产物 | 相鉴定依据、空间分布、元素迁移；直接观测与作者机制解释分开 |
| 抗蚀评价 | 渗透深度、反应层厚度、溶解/消耗量等指标的定义、测量位置与归一化；不可默认互为替代 |
| 动力学与模型 | 拟合区间、参数单位、边界条件、假设和实验验证范围 |
| 力学与失效 | 应力、开裂、剥落等区分实测、计算和推断；不从单一形貌直接升级为因果结论 |
| 比较与局限 | 条件匹配、误差/重复性、检测限与采样范围；区分未检测到和不存在 |

该清单用于提出核对问题，不预设 RE 种类、熵、温度或某种反应产物必然决定耐蚀性的方向。
