# 公共上下文与恢复策略

本页保存恢复机制和公共维护短状态。研究方向进度在D/memory/current_context.md；研究目标在D/memory/project_profile.md。D只由本会话明确选择，不从共享最近使用时间推断。

## 增量恢复

- 首次进入遵循根AGENTS，先区分公共维护与方向研究；未指定研究方向时先选择。
- 同一任务复用已读未变规则和证据，仅加载新增输入、受影响文件与本任务需要的扩展。
- 跨阶段/压缩后，读所属范围的短状态、对应计划与最近相关日志；能确定对象、授权范围、完成边界和下一步后停止回溯。
- 规则变化、实际文件与快照冲突时重读相关部分；用户当前指令优先，不凭文件日期判定科学结论正确。
- 同一对话换方向时保存原方向必要交接，绑定新D并重新加载方向配置；其他方向的规则、待办与论证不自动沿用。

## 压缩与记录

跨多个阶段、出现规则/目录结构变更、状态冲突或需要反复翻查旧对话时，可更新短状态。只保留对象、任务类型、范围、完成条件、下一步、关键约束、未决项和必要入口，不复制详细流水；科学证据仍回原文。

不保留与任务无关信息，不把被放弃建议或AI候选定位写成用户目标。压缩本身不改变证据状态、不删除历史，也不触发额外整理任务。各记录的更新触发条件以根AGENTS第7节为准；恢复时优先读当前短状态，日志用于必要回溯，inbox不再复制执行进度。
