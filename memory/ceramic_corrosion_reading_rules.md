# 陶瓷腐蚀方向：论文来源与组外作者信息

2026-09-09，依据用户本轮要求新增。仅适用于当前陶瓷腐蚀方向的候选筛选、论文入库及相关综合；通过project_profile进入，不改变AGENTS、hard_memory、通用agent或通用论文模板。科学证据要求沿用hard_memory。

## 1. 组内/组外判定

- 检查完整作者名单，出现已确认的田志林（Tian Zhilin / Zhilin Tian，包括姓名顺序、大小写及标点的规范化）时记为`internal`（组内，按用户指定的作者口径）。合作论文只要满足该条件仍按此口径记组内，不据此声称全部作者来自同一单位。
- 完整名单可核查且未出现该作者时记为`external`（组外）。只有部分作者、仅缩写Tian Z./Z. Tian、同名身份存疑或元数据冲突时记`uncertain`（待核查），优先从PDF、明确ORCID或可靠作者映射消歧，不能只凭缩写自动判断。
- collection名称、导入批次、通讯作者位置、期刊、国家或已有推荐不作为分类依据。新Scopus文献需逐篇判断；“田老师”子目录中的论文也可能是组外。
- 每篇保存判定依据、作者来源和核查日期。已入库论文在下次修订中补字段即可；本次已按现有完整作者元数据为当前10篇补记internal，未重做全文复核。
- 统计论文数量时先按DOI/item key及版本去重；组内/组外不代表质量等级，也不能替代共同数据、转引与研究独立性的核查。

## 2. 组外论文必需的补充信息

新入库组外论文时记录以下字段；缺项写null并注明具体待核原因，不阻塞已有证据足够的科学内容。候选筛选阶段可先记录作者和年份，明确单位/通讯身份/方向尚未核查。

| 信息 | 记录口径 | 优先来源与限制 |
|---|---|---|
| 一作及共同一作 | 姓名、角色；共同一作须有贡献声明 | PDF首页、equal contribution声明；不仅按排列推定共同一作 |
| 通讯作者（可多位） | 姓名、角色、标记或声明 | PDF通讯标记/说明或出版社通讯作者信息；末位作者不自动是通讯作者 |
| 发表时单位 | 每位目标作者对应的全部单位，保留英文原名、院系及规范化机构名 | PDF作者单位上标逐一映射；不能把全体单位都分配给一作或通讯作者 |
| 国家/地区 | 发表时对应单位的国家/地区，允许多值 | 优先PDF地址；不是作者国籍，也不是期刊出版国；地址未明时标待核查 |
| 发表年限 | 正式出版年；如有则另记online-first日期、卷期年及核查日 | 默认按论文发表时间理解，不推断作者学术资历；需计算距今年数时写统计基准，年差非精确周年 |
| 本文研究主题 | 该文标题/摘要和已核正文对应的材料、介质、问题、方法 | 可以从本篇提取，必须与作者当前研究方向分列 |
| 作者/团队当前主要研究方向 | 对已识别的一作和/或通讯作者写简短方向、适用人员/团队、截至日期及来源 | 优先明确身份的机构/实验室主页，其次近3–5年可核论文；单篇历史论文不够证明当前方向 |

一作与通讯作者能识别时均记录；同一人兼任时合并角色，多单位/多通讯保留各自映射，不强行选一个“代表单位/国家”。通讯作者无法识别时先完整记录一作，并保留通讯作者待核查。

## 3. 当前研究方向的核查范围

先复用已核作者/团队资料；只有首次建档、存在变更迹象或本轮需要更新时再查。单位/方向的当前信息可能变化，使用官方机构或实验室页面核实并记录访问日期；本地摘要与旧PDF只支持发表时信息。网页不可用时可写“当前方向待核查”，不把历史主题补作现状。

如据近年多篇论文概括方向，标为“AI归纳：检索范围/年份/论文来源”，与官网明确自述分开。历史任职单位与当前任职单位分别保存；不要用当前主页覆盖论文发表时单位。姓名/团队未消歧前不合并档案。不得为补齐方向而对整库作者逐一无限检索；本轮处理的论文才触发相应记录。

## 4. 存放、复用与统计

- 每篇paper增加下方方向专用字段与简短“组外作者与机构背景”段落，来源定位放在该段；不强制重填通用模板。
- 另将已入库组外论文的关键信息汇入 [[synthesis/external-literature-register]]，一行对应一位目标作者的一项发表时单位；同一作者兼任角色合并，跨单位分行。
- 作者/团队资料确需跨多篇复用时才建wiki/authors页，身份未明确时留在论文页；不因一个同名自动建立或合并团队。
- 按国家统计须说明全计数或分数计数；按论文计数时去重DOI，不能把多个作者/单位行当多篇论文。无代表性检索不能据本库数量宣称某国家/团队主导领域。
- 后续综合可按组内/组外、发表年份、机构/国家及研究主题比较，但仍逐项核查证据独立性和实验可比性。
