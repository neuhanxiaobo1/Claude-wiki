# Initialization Guide

本指南只用于首次把空白模板配置为个人知识库。已有项目先按根AGENTS选择方向，按D/memory/current_context.md恢复研究任务，不重复初始化或清理研究内容。

1. 按AGENTS.md选择或新建方向，填写D/memory/project_profile.md中已确定的研究领域、来源和偏好；研究问题未定可保留待确认。
2. 按需要登记标签和真实同义术语，不把示例当成已使用数据。
3. 已知 PDF、缓存或条目标识直接进入 pdf_read_agent；需要从 Zotero collection 选论文时才生成候选清单。
4. 先完成一篇论文及必要的局部 lint，检查证据覆盖与输出是否可用。
5. 按用户任务继续入库或修订；有比较/写作问题时再进行综合。

不要求复制 PDF 后才能阅读；不因初始化要求安装或访问当前不可用的 Zotero 工具。详细流程见 docs/zotero-workflow.md。


## 多研究方向入口（2026-09-09生效）

按根AGENTS选择已有方向或新建方向；已明确点名方向直接进入，同一任务不重复选择。D代表本会话绑定的directions/<direction_id>，文中D/是路径占位，不是实际文件夹。个人默认配置见memory/user_profile.md，研究配置及进度见D/memory/project_profile.md和D/memory/current_context.md。公共维护由根index/log管理；论文、原件、研究索引/日志和synthesis均归D。具体操作见docs/direction-workflow.md。
